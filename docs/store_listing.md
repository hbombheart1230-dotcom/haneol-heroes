# 플레이스토어 등록 초안

Play Console에 붙여 넣을 문구와 설문 답변 초안이다. 정책 문구는 콘솔 화면이 정본이므로, 붙여 넣기 전에 콘솔의 질문과 대조한다.

| 항목 | 값 |
|---|---|
| 앱 이름 (30자 이내) | 한얼: 영웅들 |
| 기본 언어 | 한국어 (ko-KR) |
| 앱 또는 게임 | 게임 |
| 무료 또는 유료 | 무료 |
| 카테고리 | 액션 |

## 짧은 설명 (80자 이내)

한 손 엄지로 대시하고 베어라. 순신과 광개토가 몰려오는 적을 휩쓰는 수묵 액션.

## 자세한 설명 (4000자 이내)

한얼의 힘을 깨운 영웅들이 하나의 전장에 섰다.

《한얼: 영웅들》은 오른손 엄지 하나로 즐기는 쿼터뷰 액션 게임입니다.
화면을 튕겨 대시하고, 적의 공격을 아슬아슬하게 피한 순간 강력한 반격을 꽂아 넣으세요.

■ 엄지 하나로 끝내는 조작
- 적 쪽으로 튕기면 대시하며 둘째 기술이 저절로, 빈 쪽으로 튕기면 회피
- 톡 치면 연타와 마무리 기술, 꾹 누르면 충전 공격
- 적의 예고 공격을 대시로 벗어나면 1초간 강화 반격

■ 매 판 달라지는 성장
- 레벨이 오르면 시간이 느려지고 주변에 먹 인장이 떨어진다. 대시로 낚아채 성장하라
- 정예를 쓰러뜨리면 기술 자체가 바뀌는 큰 변형을 얻는다

■ 서로 다른 영웅
- 순신: 푸른 해류의 검. 빠르게 누비며 벤다
- 광개토: 천둥의 정복자. 들어가서 터뜨린다
- 세종과 사임당도 준비 중

■ 수묵으로 그린 전장
- 3D로 만든 영웅을 먹선과 담채로 다시 그린 한국풍 화면

※ 역사 속 인물을 판타지로 재해석한 작품이며, 역사적 사실을 그대로 다루지 않습니다.

## 데이터 보안 (Data safety) 예상 답변

- 앱이 사용자 데이터를 수집하거나 공유하는가: **아니요**
  - 네트워크 기능, 광고, 분석, 계정이 없다.
  - 기기에 저장하는 것은 조작 설정과 마지막으로 고른 영웅(`user://settings.cfg`)뿐이며 기기 밖으로 나가지 않는다.
- 요청하는 권한: 없음 (현재 내보내기 설정 기준)
- 광고 포함: 아니요
- 대상 연령: 13세 이상 권장 (아동 대상 정책 적용을 피하고, 판타지 전투가 있으므로)

광고·분석·결제를 붙이면 이 답을 다시 써야 한다.

## 개인정보처리방침 (초안)

Play Console은 개인정보처리방침 URL을 요구할 수 있다. 저장소가 공개라서 GitHub Pages나 공개 문서에 올려 링크하면 된다. 아래 문구에서 연락처는 사용자가 채운다.

> **한얼: 영웅들 개인정보처리방침**
>
> 《한얼: 영웅들》(이하 "앱")은 이용자의 개인정보를 수집, 이용, 저장, 공유하지 않습니다.
>
> - 앱은 인터넷에 연결하지 않으며, 광고·분석·계정 기능이 없습니다.
> - 앱이 기기에 저장하는 정보는 조작 설정과 마지막으로 선택한 영웅뿐이며, 이 정보는 기기 밖으로 전송되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.
> - 앱은 기기의 위치, 연락처, 사진, 카메라, 마이크 등에 접근하지 않습니다.

## 내부 테스트 절차 (계정 승인 뒤)

1. Play Console → 앱 만들기 (위 기본 정보)
2. 테스트 → 내부 테스트 → 새 버전 만들기 → `build/android/haneol-heroes.aab` 업로드 (`tools/build/export_aab.ps1`로 빌드)
3. Play 앱 서명 사용에 동의 (업로드 키는 `%USERPROFILE%\.haneol-keys\`)
4. 테스터 목록에 본인 구글 계정 추가 → 참여 링크로 설치
5. 이후 새 빌드마다 `version/code`를 1씩 올려 업로드
