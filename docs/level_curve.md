# 판 안 경지 · 패 시간표

점수(공력)를 모아 **경지**가 오르면 그 자리에서 능력치·기술 모습이 오르고 **패** 1장이 적립된다. 싸움은 멈추지 않는다.
패는 물결 사이 숨 고르기에서 고른다. 판 안 경지는 저장하지 않는다 (판마다 1부터). 화면 글씨는 우리말: 레벨 → 경지, 레벨 업 → 경지 오름, 카드 → 패, 보스 → 우두머리 (코드 식별자는 level·card 그대로).

- 코드: `scripts/run/score_feed.gd`(점수원·상한), `level_rules.gd`(곡선·패 계획), `run_levels.gd`(경지 오름 보상·숨 고르기), `scripts/ui/hero_badge.gd`(왼쪽 위 영웅 묶음)
- 데이터: `data/runs/level_rules.tres`, `data/runs/score_table.tres`, `data/heroes/levels/<영웅>_level_up.tres`, `HeroData.portrait_rect`
- 시뮬: `python tools/sim/level_curve_sim.py [--check]` (곡선·물결을 바꾸면 다시 돌려 이 표를 갱신)

## 화면 (사용자 선택 (다))

왼쪽 위에 세로로: 둥근 영웅 얼굴 + 둘레를 도는 공력 고리 + 경지 도장 → 체력 띠(숫자) → 패 "× n" · 처치 수 → 행동 점수 글씨("연타 +2") → 경지가 오르면 "경지 오름" · "패 +1 · 다음 숨 고르기에서 고른다". 위쪽 가운데는 우두머리·중간 우두머리 띠 전용(`BossBarDrawer.TOP_FREE`, 중간 우두머리는 #83에서 BOSS_GROUP에 들어가 같은 자리), 시간은 톱니 단추 아래. 맞으면 얼굴이 붉게 번쩍·흔들림.

## 점수표 (score_table.tres)

| 행동 | 점수 | 상한 |
|---|---|---|
| 처치 | EnemyData.xp × 무대 xp_mult (한산 1.61, 나머지 1.48 → 판 전체 약 240) | 적 수가 정해져 있음 |
| 연타 4타 마무리 | 2 | 3초에 1번, 물결당 8번 |
| 회피 성공 | 2 | 2초에 1번, 물결당 8번 |
| 반격 명중 | 4 | 1초에 1번, 물결당 8번 |
| 충전 기술 다 모아(95%↑) 맞힘 | 4 | 2초에 1번, 물결당 8번 |

## 경지 · 보상 (level_rules.tres)

- 필요 점수: 14, 18, 22, 26, 30, 34, 38, 42, 46, 이후 +4씩 (앞쪽에 몰림: 보통 실력 첫 경지 오름 9~15초)
- 경지가 오를 때마다 패 1장. 2경지마다(3·5·7·9…) 영웅 능력치 한 번 (`level_up`: 최대 체력 +6/+8/+5/+5 — 순신/광개토/세종/사임당, 기본 공격 피해 ×1.04, 정수라 최소 +1).
- 모든 기술 모습 단계(`SkillDef.vfx_level`, 강화로 오른 단계에 더해짐): 첫 경지 오름(경지 2, 보통 9~15초)에 +1 — 기본 모습에 20~30초 넘게 머물지 않게 — 그 뒤 경지 4·6·8·10…마다 +1. 스킬 세션 문턱 stage_from = [0, 1, 3, 6] (SkillGrowthData)과 맞춤.
- 숨 고르기: 한 번에 최대 2번 고르기, 패 3장까지 씀 (3장이면 하나가 2단계로 합침), 넘는 패는 다음으로. 패가 없어도 1장 보장. 우두머리 직전 숨 고르기(④ 끝, WaveRunner BOSS_WAIT)는 남은 패 전부 (최대 3번, 넘치면 합침). 정예·중간 우두머리 큰 변형은 그 위에 따로.
