## 3. 데이터 보안 (Data safety)

**결론:** "수집·공유 없음"이라고 답해도 된다. 인터넷 권한이 없고(실제 APK 권한은 VIBRATE 하나), 네트워크 코드도 없다. 저장하는 것은 기기 안 `user://settings.cfg` 하나이고, 기기 밖으로 나가지 않는다.

| 질문 | 넣을 답 | 근거 |
|---|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하는가 | 아니요 | 기기 밖으로 보내는 경로가 없다. 기기 안에만 두는 데이터는 Google 기준 "수집"이 아니다 |
| (아니요이면 아래 질문은 나오지 않음) 전송 중 암호화 | 해당 없음 | 전송 자체가 없음 |
| 데이터 삭제 요청 방법 | 해당 없음 | 앱을 지우면 기기 안 기록도 지워진다 |

**사실 확인 (2026-11-24)**

- **네트워크 코드 없음:** `scripts/`·`addons/health_hitbox_hurtbox/`·`tools/`에 HTTPRequest, HTTPClient, StreamPeerTCP, PacketPeerUDP, WebSocket, ENet, OS.shell_open, 광고·분석·Firebase가 없다.
- **권한:**
  - 내보내기 설정 "Android"·"Android Play (AAB)" 모두 `permissions/vibrate=true`만 켜져 있다.
  - `aapt2 dump permissions build/android/haneol-heroes-release.apk`의 결과는 `android.permission.VIBRATE` 하나다.
- **저장 (`GameSettings`, ConfigFile):**
  - 설정: sfx·music 크기, 진동, 노랫소리, 이야기, 기술 단추, 적 체력, 연타 글씨, 개발 수치, 조작 안내
  - 진행: hero_id, stage_id, intro_seen, seen_stories, cleared_stages, hero_clears, hero_cleared, stage_records
- **기기 로그:** 판이 끝날 때 성능 한 줄을 logcat에 남긴다. 기기 안에만 있고 밖으로 보내지 않는다.
- **조건:** AAB를 새로 빌드할 때 INTERNET 권한이 붙지 않는지 다시 본다. Godot 디버그 빌드는 원격 디버그용으로 INTERNET을 넣는다. 비공개 테스트에는 **릴리스 AAB**를 올린다.

## 4. 비공개 테스트 올리는 순서 (참고)

1. 테스트 → 비공개 테스트 → 트랙 만들기 → 테스터: Google 그룹 `haneol-heroes@googlegroups.com`
2. 새 버전 → `build/android/haneol-heroes.aab` 업로드 (`tools/build/export_aab.ps1`, Play 앱 서명 동의)
3. 국가: 대한민국. 버전 이름 0.4.0, 다음 빌드마다 `version/code` +1
4. 등록정보(`store_listing.md`)와 그림(`build/release/store/`)을 넣고 검토 제출
5. 개인 개발자 계정이면 비공개 테스트 조건(테스터 수·기간)이 Console에 나온다. 그 조건을 따른다.
