# 타격감 · 스킬 적중 · 몹 밀림 벤치마크 (2026-11-21)

목적: "많이 좋아졌는데 타격감, 스킬 맞는 거, 몹에 밀리는 거 등을 더 연구" 요청에 대한 조사.
코드 변경 없음. 우리 수치(커밋 73a31aa 기준, 코드·데이터에서 직접 읽음) ↔ 레퍼런스 게임 수치 비교 → 차이 목록 → 문제별 선택지.

표기: **실측** = 게임 데이터·데이터마인·개발자 발언·프레임 카운트. **추정** = 가이드·커뮤니티 인상·튜토리얼 기본값. **없음** = 인용 가능한 수치를 못 찾음 (지어내지 않음).
60fps 기준 1프레임 = 16.7ms.

> 한계: Hades/Hades II, Archero, Brawl Stars(속도 외), Soul Knight, Halls of Torment, Diablo Immortal 의 히트스톱·플래시·흔들림 수치는 웹에 공개된 것이 없다. 이 게임들은 "어떤 설정 토글이 있는가" 같은 규칙만 인용했고, 숫자는 격투게임·스매시·몬스터헌터·LoL·Brotato·Vampire Survivors·플랫폼 가이드에서 가져왔다. 더 정확히 하려면 직접 녹화해 프레임 단위로 세야 한다 (선택지 E 참고).

## 2. 우리 수치 (코드·데이터에서 직접 읽음)

화면 720×1280 세로. 적 몸 반경 16 (충돌 레이어 2), 적 피격 판정(HurtBox) 반경 22. 플레이어 몸 반경 22, 접촉 감지 반경 30.

### 2.1 타격감

| 항목 | 우리 값 | 위치 |
|---|---|---|
| 평타 히트스톱 | **맞은 적만** 0.05s (3f), 피해 20 이상 0.08s (5f). 정지 중 좌우 떨림 | `combat_feel.tres` hit_freeze, `enemy.gd` freeze |
| 처치 히트스톱 | 게임 전체 0.03s (2f), 0.25s에 한 번까지 | kill_freeze, kill_freeze_min_gap |
| 스킬 히트스톱 | 게임 전체 0.06–0.1s, 속도 0.05배 (반격·정복자·해시계·매화만) | 각 스킬 `hit_stop` |
| 정예·보스 마무리 | 0.25배 슬로 0.35s + trauma 0.6 | finisher_* |
| 번쩍임 | 0.08s (최고 0.03s) | flash_time |
| 흔들림 공식 | trauma² × 18px, 감소 2.5/s, 방향 흔들림 | feedback.gd |

| 진동 | 피격 40ms/0.6, 마무리 60ms/0.8, 스킬 임팩트 25ms/0.5, 최소 간격 0.12s | haptic_* |
| 피해 숫자 | 있음, 40 이상은 강조 | fx_layer add_number |
| 타격 효과음 | 피격마다 `hit` | Feedback.enemy_hit |

### 2.2 넉백 · 몹 반응

| 항목 | 우리 값 |
|---|---|
| 넉백 방향 | 플레이어 → 적 방향 (Brotato 1.1 방식과 같음) |
| 넉백 감쇠 | 지수 감쇠 8/s → 실제 밀리는 거리 ≈ **충격량 ÷ 8** |
| **추격과 합산** | 넉백 중에도 `velocity = 추격 + 넉백`. 적은 맞는 동안에도 계속 앞으로 걸어옴 |
| 평타 근접 넉백 | 100 (세종·사임당) / 140 (순신) / 220 (광개토) → 잡몹 12.5 / 17.5 / 27.5px. 추격(80–120px/s × ~0.12s ≈ 10–15px)을 빼면 **실제 0–15px** |
| 평타 원거리 넉백 | 50–90 → 6–11px, 추격을 빼면 **사실상 0** |
| 스킬 넉백 | 160 (지진) / 380 (정복자) / 420 (해룡참) / 520 (반격) → 잡몹 20–65px |
| 무게 등급 | knockback_scale 1.0 / 0.3 / 0.15 / 0.1. 정예(0.3)는 평타로 3–8px |
| 평타 경직 | 없음. 0.05s 정지 뒤 바로 다시 걸어옴. 기절은 일부 스킬만 |

### 2.3 몹 간격 · 플레이어 밀림

| 항목 | 우리 값 |
|---|---|
| 플레이어 ↔ 적 몸 충돌 | **없음**. 플레이어는 장애물(16)만 막힘. 적은 적(2)+장애물만 막힘 → 서로 통과 |
| 적이 서는 자리 | 적은 **플레이어 중심을 향해** 걷는다. 플레이어와의 거리 유지 규칙 없음 → 무리가 영웅 그림 위에 겹쳐 쌓임 |
| 적끼리 분리 | 반경 40, 세기 0.6 (추격 1.0과 합친 뒤 길이 1로 자름). 몸 지름 32라 몸 닿은 뒤 8px 안에서만 밀어냄. 실제 분리는 물리 충돌이 담당 |
| 접촉 피해 | 접촉 감지 30 + 적 몸 16 → 중심 거리 46px 안이면 피해. 피해 5–25 |
| 피격 무적 | 0.6s 고정 (영웅 공통) |
| 피격 반응 | 흔들림 2.9px + 진동 40ms + 효과음. 플레이어 넉백·주변 밀어내기 없음 |
| 대시 | 0.12–0.14s 완전 무적, 적 통과. 광개토만 대시로 주변 적 밀침 (520) |

| 판정 방식 | **모든 스킬이 적 중심점으로 판정** (`enemies_in_radius`, `enemies_near_segment`: 적 중심 거리 ≤ 반경/반폭). 적 몸 반경 16, HurtBox 22를 더하지 않음 |
| 그림 ↔ 판정 | 원·띠 그림 크기 = 판정 크기. 그림 가장자리에 몸이 걸친 적(중심은 밖)은 **안 맞음** |
| 띠 스킬 반폭 | 파도격 45, 뇌전 55, 발묵 72 (너비×0.6으로 이미 약간 넉넉), 성좌진 선 25 |
| 원 스킬 반경 | 정음 110, 유성 130, 해룡 170, 지진 180, 반격 230, 매화 260, 정복자 280, 해시계 300, 화폭 160–320 |
| 시전 지연 | 유성 0.25s (자기 자리), 뇌전 0.3s, 화폭 0.6s. 적 속도 65–120px/s → 지연 동안 16–72px 이동 |
| 방향 스킬 조준 | 해일·성좌진 = **마지막 이동 방향(facing)**. 적을 향한 보정 없음. 도망치며 쓰면 등 뒤 적을 못 맞힘. 파도격은 대시 방향(의도된 것) |
| 평타 조준 | 가장 가까운 적 자동 (Brawl Stars와 같음). 근접 부채꼴 120–180°, 몸에 붙은 적은 방향 무관 |
| 탄 | 판정 반경 12, 속도 650–800, 예측 사격 없음 (적 최고 120px/s라 큰 문제 없음) |

| 영역 | 레퍼런스 | 우리 | 판단 |

| **방향 스킬 조준** | Brawl Stars: 자동 조준 궁극기도 가장 가까운 적 | 이동 방향 그대로 | ❌ 도망치며 쓰면 엉뚱한 쪽으로 나감 |
| 시전 지연 | LoL 스킬샷 0.25s | 0.25–0.6s, 위치 고정 | ⚠ 화폭 0.6s는 적이 최대 72px 이동 |

### 차이 요약 (사용자 말로)

1. **"스킬이 맞는 것 같은데 안 맞는다"**: 판정이 적 중심점 기준이라, 그림 가장자리에 몸이 걸친 적이 빠진다. 그리고 해일·성좌진은 적이 아니라 이동 방향으로 나간다.
2. **"몹이 안 밀린다"**: 넉백을 추격 속도에 더하기만 해서, 잡몹이 맞으면서도 계속 걸어온다. 평타 넉백 거리가 추격으로 거의 지워진다 (원거리 평타는 사실상 0).
3. **"몹에 밀린다/파묻힌다"**: 몸끼리 부딪히지는 않지만, 적이 플레이어 중심까지 걸어와 영웅 그림 위에 겹쳐 쌓인다. 접촉 피해가 0.6s마다 들어오고 맞아도 주변이 정리되지 않는다.
4. **"타격 확인이 약하다"**: 흔들림이 제곱이라 처치·작은 스킬에서 1px도 안 된다. 진동은 반대로 플랫폼 권장보다 길다.

## 4. 문제별 선택지 (각각 2–3개 + 추천)

비용: 하 = 데이터·한두 파일, 중 = 새 로직 + 테스트, 상 = 구조 변경.

### A. 스킬이 안 맞음 (판정·조준)

| | 선택지 | 느낌 | 비용 | 위험 |
|---|---|---|---|---|
| A1 | **가장자리 판정**: 모든 스킬 판정에 적 판정 반경을 더함 (LoL 방식). 적 데이터에 `hit_radius`를 넣고 `enemies_in_radius`·`enemies_near_segment` 두 곳만 바꿈 | 그림에 걸친 적이 다 맞음. 큰 적(보스)은 더 잘 맞음 | 하 | 스킬이 일괄 강해짐 (파도격 판정 폭 +35%쯤). 밸런스 재확인 필요 |
| A2 | **방향 스킬 조준 보정**: 해일·성좌진을 쓸 때 이동 방향 ±40° 안에 적이 있으면 그쪽으로. 없으면 가장 가까운 적 무리 쪽 (Brawl Stars 자동 조준 + War Robots 유지 구역) | 도망치며 써도 적에게 감 | 중 | 일부러 다른 데로 쏘고 싶을 때 방해. 각도를 데이터로 두고 0이면 끔 |
| A3 | **그림을 판정보다 약간 작게** (판정의 90%) | 보이는 것보다 넉넉함 | 하 | A1과 같이 쓰면 효과가 겹침. 단독으로는 효과가 작음 |

**추천: A1 + A2.** A1은 가장 싸고 효과가 크다 (지금 체감 문제의 주원인). A2는 해일·성좌진에만 적용.

### B. 몹이 안 밀림 (넉백·경직)

| | 선택지 | 느낌 | 비용 | 위험 |
|---|---|---|---|---|
| B1 | **짧은 경직**: 잡몹이 맞으면 0.12–0.2s 동안 추격을 끄고 넉백만 받음 (VS 120ms 방식). 길이·대상 등급은 데이터 | 맞을 때마다 "턱" 하고 밀려나 멈칫. 평타 넉백이 실제로 보임 | 하–중 | 빠른 평타(0.55s)에 연타당하면 잡몹이 거의 못 다가옴 → 쉬워짐. 등급별로 끄기 |
| B2 | **넉백 수치만 키우기**: 충격량 ×1.5–2, 감쇠 8→6 | 단순하게 더 밀림 | 하 | 추격과 더하는 구조는 그대로라 "미끄러지듯" 밀림. 경직감은 없음 |
| B3 | **등급 규칙 뚜렷하게** (Hades II·Brotato·Lost Ark): 잡몹 = 완전 밀림 + 경직, 정예 = 갑옷 바가 있는 동안 밀림 면역 → 깨지면 기절, 보스 = 면역 + 경직 게이지 | 정예·보스가 "무겁다"가 분명해지고 갑옷 깨기가 목표가 됨 | 중–상 | UI(갑옷 바) 추가. 정예 특성(affix)과 겹치는지 확인 |

**추천: B1 먼저 (잡몹만), B3는 보스 패턴 작업 때 같이.** B1만으로 "몹이 밀린다"가 가장 크게 달라진다.

### C. 몹에 밀림/파묻힘 (군중 처리)

| | 선택지 | 느낌 | 비용 | 위험 |
|---|---|---|---|---|
| C1 | **거리 유지 고리**: 적이 플레이어 중심이 아니라 "접촉 거리"(플레이어 반경 + 적 몸 반경)에서 멈추고 고리를 따라 퍼짐. 공격 토큰(이미 있음)이 없는 적은 한 걸음 바깥에서 대기 | 영웅이 몹 무리 위에 묻히지 않고, 둘러싸인 모양이 보임 | 중 | 적이 "줄 서서 기다리는" 느낌이 될 수 있음. 토큰 수·고리 간격 튜닝 |
| C2 | **피격 시 숨 돌릴 틈**: 맞을 때 주변 적을 살짝 밀어냄 (반경 ~80, 충격 200 정도) + 피격 무적을 피해 비례 0.4–0.6s로 (Brotato) | 맞으면 주변이 한 번 정리되어 다시 움직일 수 있음 | 하 | 접촉 피해로 몹을 밀어내는 게 이상해 보일 수 있음 (작은 이펙트로 가리기) |
| C3 | **적끼리 분리 강화**: 분리 반경 40→48, 세기 0.6→1.0 | 무리가 덜 뭉침 | 하 | 많은 적이 서로 밀며 떨릴 수 있음 (지금은 물리 충돌이 대부분 처리) |

**추천: C1 + C2.** C1이 "파묻힘"의 근본 해결, C2는 싸고 바로 체감됨. C3는 C1 후에도 뭉치면.

### D. 타격 확인 (흔들림·진동·정지)

| | 선택지 | 느낌 | 비용 | 위험 |
|---|---|---|---|---|
| D1 | **흔들림 곡선 고치기**: 작은 값이 사라지지 않게 최소 크기를 두거나 지수를 2→1.5로. 처치 흔들림은 빼고 방향 킥(6px)만 남김. 스킬 trauma 0.3–0.45 (세로 폭 1–3%) | 스킬이 "쿵" 하고 처치는 킥으로 깔끔 | 하 | 많이 겹치면 어지러움. 설정에 흔들림 끄기 추가 (설정 화면 계획에 넣기) |
| D2 | **진동 짧게**: 임팩트 15ms, 피격 30ms, 마무리 40ms (Android 10–20ms 원칙) | "웅"이 "탁"으로 | 하 | 기기마다 세기 차이. 실기기 확인 필요 |
| D3 | **스킬 정지 공통화**: 큰 스킬 모두 피해 비례 정지 (기본 + k×피해, 최대 0.12s), 여러 적을 동시에 맞히면 짧게 (스매시 인원 배율 방식) | 모든 큰 스킬에 묵직한 "박힘" | 중 | 연속 스킬 때 끊김처럼 보일 수 있음 → 최소 간격 (처치 정지처럼) |

**추천: D1 + D2 (모두 데이터 수정 수준), D3는 그 다음.**

### E. (선택) 실측 보강

공개 수치가 없는 게임(Hades II, Archero, Brawl Stars)은 직접 녹화해 프레임 단위로 세야 한다: 60fps 녹화 → 타격 프레임부터 정지·번쩍임·흔들림 길이를 센다. 게임당 30분 정도. 위 선택지를 정하는 데 꼭 필요하지는 않다.
