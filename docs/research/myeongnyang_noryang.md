## 2. 전장 정체성 (한산과 다르게)

### 2.1 명량 — "울돌목, 대장선 홀로" (한 쪽 요약)

**정체성:** "한 척이 홀로 막는다". 좁은 갑판 위에 적이 사방에서 올라탄다. 바닥 전체에 **물살**이 흐른다 (사실: 사리 때 물살 11.5노트, 도중에 방향이 바뀜).

**장치 후보 [창작]**
- **물살 밀기:** 전장 전체에 한 방향(처음에는 북서 → 화면 위) 힘이 영웅과 적 모두에게 작용한다. 물살을 거슬러 대시하면 짧아지고, 타고 대시하면 길어진다.
- **물살 뒤집힘 (④물결 시작):** 화면에 "물살이 바뀐다" 문구가 뜨고 방향이 반대(남동)로 바뀐다. 뒤집힌 뒤 몇 초 동안은 **밀려난 적끼리 부딪치면 피해와 경직**을 받는다 (사실: 일본 배가 서로 부딪침).
- **들이받는 배 (우두머리 패턴):** 전장을 가로지르는 긴 직사각형 예고 → 적선이 들이받는다. 지금 있는 CHARGE 예고를 그대로 쓴다.

**5물결 [창작]**
1. 떼: 졸병 + 철포병 (물살 익히기)
2. 떼 + 새 종: **갈고리 등선병** 첫 등장 (물살 쪽으로 끌어당김)
3. 중간 우두머리: **선봉장** (구루시마를 본뜬 망령 선봉장. 이름은 아래 결정 사항). 들이받기 + 등선병 부르기
4. 떼 + 정예: 물살 뒤집힘 → 무사·사무라이 대장(정예)이 밀려 서로 부딪힘
5. 우두머리: **왜 수군 대장선의 장수** (도도를 본뜸). 단계마다 들이받는 배, 철포 일제 사격, 체력 50%에서 물살이 다시 뒤집힘

**A안 — 대장선 갑판 (추천):** 세로로 긴 판옥선 한 척의 갑판. 양옆 난간 밖은 물살(막힘)이다. 물살 밀기가 갑판 위에서도 "배가 흔들리며 쏠린다"로 읽힌다. 전장 모양이 한산과 확실히 달라진다 (넓은 갑판 → 좁고 긴 갑판).
**B안 — 물목 벼랑:** 해남 쪽 우수영 바닷가 바위 언덕에서 싸우고, 아래에 울돌목이 보인다. 그림은 새롭지만 물살 장치가 땅 위에서는 어색하다.
**추천: A안.** 사실(대장선 홀로, 물살 뒤집힘)과 플레이 장치가 바로 이어진다.

### 2.2 노량 — "밤바다, 마지막 북소리" (한 쪽 요약)

**정체성:** 한밤에 시작해 **물결마다 하늘이 밝아지고 ⑤물결에서 동이 튼다** (사실: 새벽 2시 시작, 동틀 녘 절정). 화면은 어둡고, 불빛 근처만 잘 보인다. 불붙은 나무를 던지는 조선군 (사실).

**장치 후보 [창작]**
- **어둠과 불빛:** 영웅 둘레 빛 + 불타는 소품 둘레 빛 웅덩이만 밝다. 철포병이 쏘기 직전 총구가 번쩍여 자리가 드러난다.
- **불 항아리 (깨는 물건):** 깨면 잠시 불이 붙는 곳이 생긴다 (적에게 피해, 영웅도 닿으면 조금). 지금 있는 부서지는 물건과 DamageZone을 넓힌다.
- **새벽이 밝아 옴:** 물결이 끝날 때마다 무대 조명(StageLook)이 밤 → 새벽으로 한 단계씩 바뀐다.
- **북소리 [창작, 결정 필요]:** 무대 노래 박자에 맞춰 북이 울리면 잠깐 공격이 세진다. 이순신의 마지막 말("북을 계속 쳐라")에 대한 경의다. 영웅의 죽음은 그리지 않는다.

**5물결 [창작]**
1. 떼: 졸병 + 철포병, 깜깜한 밤 (불빛 익히기)
2. 떼 + 새 종: **어둠 기습병** (어둠에서 갑자기 나타남, 지금 있는 cc_ambush 행동을 다시 씀)
3. 중간 우두머리: **구원 선단 선봉장**. 불화살(불 자리) + 기습병 부르기
4. 떼 + 정예: **창(야리) 돌격병** (지금 있는 THRUST) + 사무라이 대장. 하늘이 붉어짐
5. 우두머리: **구원군 총대장** (시마즈를 본뜸). 밤 일제 사격, 불배, 체력이 낮으면 전장 끝으로 달아나려 한다 (사실: 시마즈는 살아서 달아남) → 막아서 쓰러뜨리면 동이 트며 승리. 끝은 관음포.

**A안 — 밤바다 연합 선단 (추천):** 불타는 배들이 이어진 갑판에서 싸우고, 물결마다 새벽에 가까워진다. 마지막에 관음포가 보인다.
**B안 — 관음포 새벽 포구:** 동틀 녘 얕은 포구. 갯벌과 얕은 물이 발을 느리게 한다. 밝고 명확하지만 "밤 싸움"이라는 가장 큰 차별점이 사라진다.
**추천: A안.** 어둠 → 새벽의 흐름이 한 판 4분 안에서 이야기를 만든다.

### 2.3 적 이름 결정 필요 (사용자)
- 지금 보스 이름은 "왜군 망령 수군 장수"처럼 직책만 쓴다. 명량·노량 우두머리를 **실존 인물 이름(구루시마·도도·시마즈)으로 부를지, "망령 선봉장" 같은 직책으로만 부를지**는 사용자가 정한다. 망령 군대 원칙(3.1)을 보면 **직책 이름 + 설명 문구에 역사 언급**이 안전하다고 본다.
- 노량은 이순신이 전사한 곳이다. 연출 수위(북소리, 마지막 말 인용 여부)를 사용자가 정해야 한다.

## 4. 만드는 순서와 작업량

1. **데이터 시제품 (각 0.5일, 크레딧 0):** 새 `StageTheme` 2개 + 5물결 + 조명. 그림은 한산 지도와 소품에 색만 바꿔 임시로 쓴다. 폰에서 "다른 전장 느낌"이 나는지 먼저 본다. 노량은 밤 조명만으로도 많이 달라진다.
2. **장치 코드 (명량 1.5~2.5일, 노량 1.5~2.5일):** 물살 장·뒤집힘, 조명 단계·불 자리·총구 번쩍임. 순수 로직은 RefCounted로 만들고 gdUnit 테스트를 단다.
3. **개념도 (GPT, 사용자 승인):** 지도 2장, 소품, 잡몹·우두머리 개념도. 사실 고증(판옥선, 아타케부네·세키부네, 임진왜란 왜군 복식)을 맞춘다.
4. **적 모델 (Meshy, 한 종에 약 0.5일 + 굽기 맞추기):** 잡몹 → 중간 우두머리 → 우두머리 순서. 우두머리는 실시간 3D 대상이다 (live3d 가공 0.5일 추가).
5. **우두머리 패턴 (각 1~2일):** 들이받는 배·물살 재뒤집힘 / 밤 일제 사격·불배·달아나기. 보스 결정 시뮬레이션(#66) 테스트를 쓴다.
6. **음악 (사용자 Suno) → 구간 자르기 0.5일 / 효과음 0.5일.**
7. **영웅별 무대 목록 0.5일 + 폰 시험.**

**어림 (세션 작업일, 사용자 결정·폰 시험 대기 제외):** 명량 약 6~8일, 노량 약 6~8일. 공통 부분(무대 목록, 불 자리, 조명 단계)을 같이 쓰면 둘 합쳐 **약 10~13일**.
**추천 순서:** 노량 데이터 시제품(밤 조명만으로 차이가 크고 크레딧 0) → 명량 물살 장치(새 플레이의 핵심) → 개념도 승인 → 모델 → 우두머리 패턴 → 음악.
