# 타격감 2차 연구: 무기 든 동작 · 무기 끝 이펙트 · 수치 재점검 (2026-11-22)

배경: 적 15종(왜군·거란·여진)과 영웅이 무기를 든 새 디자인으로 다시 구워지는 중. 타격감 1~3단계(PR #32~#34)는 `art/enemy-rebake`에 들어갔다.
이 문서는 **조사와 선택지만** 담는다. 고르기 전에는 코드·수치를 바꾸지 않는다. 유료 호출(Meshy)도 하지 않았다. 동작 미리보기는 Meshy 동작 라이브러리의 무료 미리보기 GIF로 확인했다.

표기는 1차 문서(`docs/research/game_feel_benchmark.md`)와 같다. **실측** = 프레임 데이터·데이터마인·개발자 발언, **추정** = 가이드·인상, **없음** = 못 찾음.

---

## 0. 한 줄 요약

**지금 가장 약한 곳은 "무기와 피해가 따로 논다"는 점이다.**
- 적 공격 동작은 예고(0.45~0.9초)와 상관없이 0.6초에 끝난다.
- 영웅 근접은 휘두르기 **전에** 피해가 들어간다.
- 구운 6프레임이 긴 동작(1.5~7.4초) 전체에서 고르게 뽑혀, 내려치는 순간이 빠지는 동작도 있다.
- 적 공격에는 **소리가 하나도 없다** (조총도 소리 없이 쏜다).

이 넷을 고치는 것이 무기 그림이 들어온 뒤 가장 값싸고 효과가 큰 다음 단계다 (5절 순위).

### 1.4 구운 동작과 실제 피해 시점이 어긋나는 문제 (코드에서 확인)

| 어디 | 지금 | 결과 |
|---|---|---|
| 굽기 (`tools/bake/bake_sprites.gd:287`) | 동작 **전체 길이**에서 frames개를 고르게 뽑는다 (예: 7.4초 도끼 → 1.2초 간격) | 내려치는 0.3초가 두 샘플 사이에 끼면 사라짐. 앞뒤 대기 자세가 프레임을 차지 |
| 적 공격 재생 (`EnemySprite.update`) | 예고 시작 때 attack 6프레임을 10fps로 재생 = 0.6초 | 예고 0.7~0.9초인 적은 **휘두른 뒤 0.1~0.3초 멈춰 있다가** 피해가 들어감 |
| 영웅 근접 (`AutoAttack._melee`) | 휘두르기 시작과 **같은 프레임에** 피해 | 칼이 닿기 약 0.15~0.2초 **전에** 적이 맞는다 |
| 영웅 원거리 | release_delay로 던지는 순간에 발사 (세종 0.17초) | ✅ 이미 맞춤 |

레퍼런스: Diablo II는 동작마다 **"액션 프레임"** 하나에 피해와 발사를 건다 (실측, 25fps 기준 활 10프레임 = 0.40초, https://maxroll.gg/d2/resources/breakpoints-animations). 스매시도 히트스톱이 **맞닿는 프레임**에 시작한다 (실측, https://www.ssbwiki.com/Hitlag).

**선택지**

| | 내용 | 느낌 | 비용 | 위험 |
|---|---|---|---|---|
| W1 | **잘라 굽기 + 맞닿는 프레임 표시**. 굽기 작업에 `from`/`to`(초)와 `strike` 프레임 번호를 넣음 (예: 237은 3.4~4.8초만). 시트 데이터에 strike 프레임 저장 | 6프레임이 모두 공격 동작에 쓰이고, 내려치는 장면이 반드시 들어감 | 하 (굽기 도구 + 작업 파일, 다시 굽기는 무료) | 동작마다 from/to를 눈으로 정해야 함 (미리보기 시간표는 1.2절) |
| W2 | **피해 시점에 맞춰 재생**. 적은 예고 동안 `windup_ratio`로 0→strike 프레임을 진행하고, 피해 순간 strike 프레임이 되며, 나머지는 회복 시간에 재생. 영웅 근접은 strike 프레임까지 피해를 늦춤 (원거리처럼 데이터 `melee_delay`, 0.08~0.15초) | 칼이 닿는 순간에 맞고 멈추고 소리가 남 | 하–중 (EnemySprite·AutoAttack) | 영웅 피해가 0.1초 늦어지면 반응이 둔해질 수 있음 → 2.5배 규칙대로 가벼운 무기는 0.08초 |
| W3 | 동작만 바꾸기 (1.3 표대로 크레딧 사용) | 자세는 맞지만 타이밍은 그대로 | 크레딧 약 39 | W1·W2 없이는 효과 절반 |

**추천: W1 → W2 → W3 순서.** W1·W2는 지금 동작으로도 효과가 있고 무료다. W3은 W1 뒤에 해야 새 동작이 제대로 담긴다.

### 1.5 무기별 시간 (레퍼런스로 정한 범위)

인용 기준:
- 사람 반응 약 240~273ms (실측, Model Human Processor·HumanBenchmark)
- 폰 터치 지연 50~200ms (실측, https://arxiv.org/pdf/2408.02525)
- → 모바일 예고 **최소 약 400ms**
- Dark Souls 3의 예고+공격 최소 340ms는 패드 기준 (실측, https://www.gamedeveloper.com/game-platforms/anatomy-of-an-enemy-attack-in-dark-souls-3)
- 약공격과 강공격의 준비 시간 차이는 약 2.5배 (SF6, 실측)

| 무기 | 적 예고 | 판정 | 회복 (빈틈) | 우리 지금 |
|---|---|---|---|---|
| 찌르기 (창) | 450–550ms | 50–80ms, 좁은 직선 | 150–250ms | 창병은 예고 0.6~0.7 / 회복 0.3~0.5 → 예고를 0.5로 줄이고 판정을 좁은 직선으로 |
| 한 손 베기 | 500–650ms | 60–100ms, 부채꼴 | 200–300ms | ✅ 대체로 맞음 |
| 두 손 무거운 (도끼·노다치·몽둥이) | 700–1000ms | 80–130ms, 넓은 호 | 350–500ms (처벌 시간) | 중갑 예고 0.8~0.9 ✅, 회복 0.6~0.8 ✅ |
| 방패 밀치기 | 500–700ms | 60–100ms | 250–350ms | 해당 패턴 없음 (220을 쓰면 짧은 밀치기 + 넉백) |
| 활 | 겨눔선 600–1000ms (Archero 약 1초, 추정) | 즉시 발사 | 150–250ms | 궁수 예고 0.7~0.8 ✅ |
| 조총 | 겨눔선 700–1000ms, 발사 때 불꽃 1~2프레임 | 매우 빠른 탄 | 400–600ms (장전) | 조총병 예고·회복은 활과 비슷 → **예고를 0.9~1.0으로 늘리고, 탄을 빠르게 하고, 재장전을 길게** |

영웅 자동 공격은 0.55~0.8초 주기 안에 들어가야 하므로 준비를 짧게 잡는다:
- 찌르기 80~150ms, 베기 100~180ms, 두 손 200~300ms
- 이것이 W2의 `melee_delay`가 된다.

## 2. 무기 끝에 이펙트 붙이기

### 2.1 지금

| 이펙트 | 지금 위치 |
|---|---|
| 근접 초승달 (`AutoAttack._draw`) | 영웅 중심에서 사거리 0.85 거리의 호 (무기와 무관) |
| 원거리 발사점 (`release_offset`) | 영웅 중심 + 바라보는 방향 × x + 위로 y. **방향마다 같은 값** |
| 맞은 불꽃·먹 튐 | 맞은 적의 중심 |
| 적 화살·조총 탄 | 적 중심에서 출발 |

무기를 들기 전에는 이걸로 충분했다. 이제는 칼끝·총구가 보이므로, 탄이 총구가 아닌 배에서 나오거나 베는 호가 칼과 다른 쪽에 그려지면 눈에 띈다.

### 2.3 선택지

| | 내용 | 정확도 | 비용 | 위험 |
|---|---|---|---|---|

**추천: T2.** 다시 굽는 김에 데이터를 같이 만들면 손이 안 가고, 영웅·적 모두에 쓴다. T2가 어려운 모델은 T1의 strike 프레임 값으로 대신한다.
- 쓰는 곳: 탄 발사점(조총 불꽃·화살), 영웅 근접 초승달의 중심, 맞은 불꽃 방향.
- 맞은 불꽃 자체는 맞은 적 위가 맞다 (지금 그대로).

### 3.2 아직 약한 곳 (판단, 약한 순)

1. **무기와 피해 시점이 어긋남** (1.4절). 이번에 무기 그림이 생겨 더 잘 보이게 됐다.
2. **적 공격에 소리가 없음.**
   - 예고·휘두름·조총 발사·활시위 소리가 없고, 플레이어가 맞을 때 피격음만 난다.
   - 그래서 조총병이 쏴도 조용하다.
   - 레퍼런스: Overwatch는 "소리만 듣고도 플레이"하게 설계했다 (1차 문서 6.1).
3. **원거리 적의 겨눔선이 무기와 따로 놂.** 탄이 몸 중심에서 나오고, 겨눔 중 무기 끝에 빛이 모이는 표시가 없다 (Archero: 빨간 선 약 1초).
4. **창·두 손 무기가 거리만 다를 뿐 같은 몸.** 3.1의 `reach_px`와 1.5의 판정 모양(창 = 좁은 직선)이 아직 없다.
5. (작음) 보스 휘청이 잦다 (3.1).

**1~4는 유료 없이 한 묶음으로 할 수 있다.**
