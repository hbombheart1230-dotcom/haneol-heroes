# 전장마다 다른 맛 — 무대 장치 연구 (2026-11-23)

사용자 말: "다른 영웅의 전장을 갈 때 뭔가 특징점이 있으면 좋을 것 같은데, 다 똑같은 전장이 아닌."

이 문서는 **연구·제안**이다. 코드는 바꾸지 않았다. 아래 안은 사용자가 고른 뒤에 구현한다. 명량·노량·창덕궁·동궁전과 광개토의 나머지 두 전장에 관한 내용은 아직 정해지지 않은 세계관이라서 `docs/scenario.md`에 넣지 않는다.

---

## 0. 한 쪽 요약

**왜 지금 네 전장이 다 똑같이 느껴지나?** 차이가 그림에만 있고 플레이에는 없다.

- **땅 모양이 같다.** 네 지도 모두 "가운데가 빈 직사각형 + 가장자리 장식"이다. 갑판의 대포, 궁궐 품계석, 초충도의 풀은 모두 가장자리에 붙은 막힘 원(`map_blockers`)일 뿐이다.
- **적 틀이 같다.** 네 군대가 똑같은 다섯 자리(졸병·원거리·중장·정예·보스)를 쓴다 (`docs/enemy_design.md`).
- **무대 장치가 없다.** 전장 고유의 장치는 부서지는 항아리(탕약) 하나뿐이고, 그것도 네 곳이 같다.
- **바탕 소리가 없다.** 무대마다 다른 것은 곡과 색뿐이다.

**하데스에서 가져올 원리.** 설치본 데이터를 읽기만 해서 얻은 구조이고, 연출은 가져오지 않는다.

1. **장치는 양쪽을 다 친다. 적에게는 훨씬 세게.** 하데스 함정은 중립이고, 적이 받는 피해는 20배다 (`BaseTrap.NonPlayerMultiplier = 20`). 그래서 전장 자체가 무기가 되고, 잘하는 사람은 적을 장치로 끌어들인다.
2. **정해진 박자와 예고.** 용암은 10초마다 4~5곳에 0.1초 간격으로 튄다. 함정은 0.2~4초 전에 예고한다. 박자를 읽는 것이 곧 재미다.
3. **구역의 성격을 숫자 하나가 바꾼다.** 벽에 부딪힐 때 받는 피해 배율이 구역마다 1.0 → 1.5 → 2.0 → 2.5로 오르고, 부서지는 보물 상한도 3에서 6으로 늘어난다.
4. **색·소리·적 구성이 구역마다 확 다르다.** 청록, 용암 빨강, 금빛, 독 초록처럼 바뀐다.

**제안: 네 전장이 서로 다른 축 하나씩을 맡는다.** 겹치지 않게 나눴다.

| 전장 | 축 | 추천 장치 (★) | 한 줄 |
|---|---|---|---|
| 한산 갑판 | **선** (시간에 맞춰 긋는 줄) | ★A 포격선 + C 화약통 | 북소리 뒤 갑판을 가로지르는 포격 줄. 적을 줄 위로 끌어들이면 쓸어 버린다 |
| 만주 벌판 | **번지는 면** | ★C 들불 | 마른 풀밭에 불이 붙어 번진다. 번개·유성이 불을 붙이고 물결이 끈다 |
| 경복궁 | **건물** (막는 구조물) | ★B 품계석·기둥 엄폐 | 돌이 화살·총알을 막는다. 여진 궁수와 숨바꼭질을 한다 |
| 초충도 | **숨기** (생명이 사는 그림) | ★A 풀숲 숨기 | 그린 풀숲에 들어가면 적이 놓친다. 풀숲에서 나오며 치면 기습 |

**원정에서 달라지는 이유.** 장치가 **기술의 성질**(물·번개·별·먹)과 **영웅의 체급**(무거움·멀리서·부르기)에 반응한다. 같은 들불이라도 광개토는 불을 붙이고, 순신은 불을 꺼서 길을 낸다. 사임당은 풀벌레가 타서 조심해야 하고, 세종은 멀리서 유성으로 불씨를 떨어뜨린다. 자세한 표는 §4에 있다.

**영웅당 세 전장으로 늘릴 때.** 영웅마다 장치의 **축은 그대로** 두고 **변주 하나 + 새 겹 하나**를 더한다.

- 순신: 한산 포격선 → 명량 거꾸로 도는 물살 → 노량 밤의 불배.
- 세종: 경복궁 엄폐 → 창덕궁 연못 다리 → 동궁전 여닫는 문.

자세한 것은 §5.

**구현 크기.** 지금 코드(`StageTheme` 데이터, `Arena`의 막힘·빛 웅덩이, `BreakableField`, 적 공격 예고 모양)로 절반 정도는 된다. 공통 틀 하나가 새로 필요하다: `StageTheme.hazards: Array[StageHazardData]`와 장치 노드 몇 개. 추천 네 개를 다 만들면 대략 다음과 같다.

- 공통 틀 1
- 무대별 장치 4 (파일당 150~250줄)
- 그림 8~12장
- CC0 소리 6~10개

순서 추천: **한산 포격선**(틀 만들기, 가장 쉽고 효과 큼) → 경복궁 엄폐 → 만주 들불 → 초충도 풀숲. 자세한 것은 §6.

**사용자가 정할 것** (§7):

1. 영웅이 장치에 맞을지 (중립 원칙). 추천: 맞되 작게.
2. 무대당 장치 하나로 시작할지 둘로 할지.
3. 위 추천 네 개를 그대로 갈지.
4. 보스가 장치를 쓸지 (3단계 군령에서).

## 1. 벤치마크 — 구조와 원리만

### 1.1 하데스: 구역마다 무엇이 다른가 (설치본 `Content/Scripts` 읽기만)

| 다른 점 | 데이터에서 본 것 | 원리 |
|---|---|---|
| 함정 종류 | 첫 구역은 가시 함정 (`TrapsBiome1 = SpikeTrap`), 둘째·셋째 구역은 독가스 (`TrapsBiome2 = GasTrapPassive`) | 구역마다 함정 **한 종류**가 정체성이다. 여러 개를 섞지 않는다 |
| 함정은 중립 | `TargetGroups = { "GroundEnemies", "HeroTeam", ... }`, `BaseTrap.InheritFrom = IsNeutral` | 적도 맞는다 → 끌어들이는 재미 |
| 적에게 더 세다 | `BaseTrap.OutgoingDamageModifiers.NonPlayerMultiplier = 20` | 영웅에게는 조심할 것, 적에게는 무기 |
| 예고 길이 | 가시 0.2초 · 도끼 0.3초 · 독 1.5초 · 가스 3초 · 어떤 것은 4초 (`PreAttackDuration`) | 빠른 것은 밟은 자리에서 터지고, 넓은 것은 오래 예고한다 |
| 다시 쓰기까지 | 가시 2초, 가스 15~20초 (`PostAttackCooldown`) | 넓고 센 것일수록 드물게 |
| 구역 재해 | 둘째 구역 용암 튐: `HazardData{ SpawnRate = 10, SpawnsPerBurstMin 4, Max 5, SpawnStagger 0.1 }` | **방마다가 아니라 구역 전체에** 일정한 박자로 깔리는 재해 |
| 벽 부딪힘 | `WallSlamMultiplier` 구역 1 (없음) → 1.5 → 2.0 → 2.5 | 숫자 하나로 "벽으로 밀어붙이기"의 값어치가 구역마다 달라진다 |
| 보물 항아리 | `MaxHighValueBreakables` 3 → 마지막 구역 6 | 부서지는 것의 모양과 보상이 구역마다 다르다 |
| 카메라 | 둘째 구역 `CameraWalls = true`, `SoftClamp` 0.0 (나머지 0.75) | 지형이 카메라 움직임까지 바꾼다 |
| 색 | 녹화 모아 보기 (`build/video/hades_overview.png`): 청록 → 용암 빨강·검정 → 금빛 → 녹갈색 | 구역마다 색온도가 크게 다르다. 한 화면만 봐도 어디인지 안다 |

**땅 모양.** 녹화를 보면 구역마다 걸을 수 있는 땅 자체가 다르다. 용암이 바닥을 파먹은 구역은 좁은 다리와 섬이 되고, 기둥이 많은 구역은 엄폐가 되고, 넓은 뜰은 몰려오는 적과 싸우는 곳이 된다. 같은 적이라도 땅 모양이 다르면 싸움이 달라진다.

### 1.2 뱀서류 (생존 떼 싸움): 무대가 플레이를 바꾸는 방식

- **지도 모양이 곧 난이도다.** 끝없는 들판(어디로든 빠질 수 있다)과 좁은 복도·가로로 긴 다리(떼가 양쪽에서 막는다)는 같은 영웅이라도 완전히 다른 경험이 된다.
- **무대 고유의 떼.** 무대마다 떼가 **오는 방향**과 **모양**이 다르다. 한쪽에서 몰려오는 큰 물결, 둘레를 에워싸는 고리, 지나가는 행렬 같은 식이다. 피하는 길이 무대마다 다르다.
- **부서지는 빛 (조명·화로).** 깨면 회복이나 보물이 나온다. 무대마다 모양만 바꿔도 맛이 바뀐다 (우리 항아리와 같은 자리).
- **무대 규칙 하나.** 어떤 무대는 시간이 지날수록 빨라지고, 어떤 무대는 보물이 더 나온다. 무대 선택에 **위험과 보상**의 차이를 둔다.

### 1.3 디아블로류 (내려다보는 액션 RPG)

- **환경 피해.** 부서지는 벽·매달린 물건·폭발 통을 쳐서 아래 적을 쓸어 버린다. 맵에 놓인 무기다.
- **사당 (잠깐 힘).** 밟으면 30초쯤 강해진다. 어디로 갈지를 바꾼다.
- **구역 성질.** 어두운 지하(시야가 좁다), 좁은 복도(떼가 줄을 선다), 넓은 들판(둘러싸인다). 땅 모양과 빛이 싸움 방식을 정한다.
- **군단 성질.** 구역마다 적 계열의 버릇이 다르다. 되살리는 무리, 터지는 무리, 멀리서 쏘는 무리가 있어서 우선 잡을 적이 바뀐다.

### 1.4 세 가지에서 뽑은 설계 원칙 (이 문서의 자)

1. **전장마다 장치 하나가 주인공이다.** 여러 개를 섞으면 세로 화면에서 읽기 어렵다. 둘째 장치는 작게 둔다.
2. **장치는 중립이되 적에게 훨씬 세다.** 영웅이 받는 피해는 잡몹 한 대 정도이고, 적이 받는 피해는 잡몹을 한 번에 지울 정도다.
3. **박자와 예고.** 예고는 바닥 모양(줄·원·면)으로 하고 0.8~1.5초를 준다. 소리(북·징)로도 예고한다. 엄지 하나로 피할 수 있어야 한다.
4. **영웅의 기술과 반응한다.** 원정의 맛이 여기서 나온다 (§4).
5. **땅 모양을 조금이라도 바꾼다.** 지금은 네 곳 모두 빈 직사각형이다.
6. **색·바탕 소리를 무대마다 크게 다르게.** 이미 `StageLook`이 있다. 바탕 소리(파도·바람·풍경·풀벌레)는 아직 없다.

## 2. 지금 가진 것 (구현 크기를 잴 자)

| 있는 것 | 파일 | 장치에 쓸 수 있는 것 |
|---|---|---|
| `StageTheme` (무대 데이터) | `scripts/world/stage_theme.gd` | 곡, 색, 소품, 막힘 원, 부서지는 것, 적 구성, 물결, 카메라 확대. **장치 목록을 넣을 자리** |
| `StageLook` + `LightPools` | `stage_look.gd`, `light_pools.gd` | 바닥 빛 웅덩이와 소품 둘레 빛 → **빛 구역** 장치에 그대로 쓴다 (경복궁 석등, 노량 불배) |
| `Arena` + `Obstacles` | `arena.gd`, `obstacles.gd` | 원 막힘 (StaticBody2D 5번 층), 적이 막힘을 돌아간다 (`steer_around`). **엄폐**와 **부서지는 막힘**의 바탕 |
| `BreakableField` + `BreakableData` | `breakable_field.gd`, `breakable_data.gd` | 깨면 탕약. 지금은 무대당 한 종류뿐 → **종류 목록 + 깨질 때 효과**(폭발)로 넓히면 화약통이 된다 |
| 적 공격 예고 모양 | `enemy_attack.gd` (`contains`: 원·부채꼴·직사각형) | 장치 예고와 판정 모양을 **같은 모양 코드로** 쓸 수 있다 (줄 = CHARGE 직사각형, 원 = SLAM) |
| `WaveSetData` | `wave_set_data.gd` | 물결마다 적 구성. **나오는 자리**(문·승강구)는 아직 없다: 영웅 둘레 거리(spawn_min/max)로만 정한다 |
| 무대 진행 (원정) | `claude/stage-select` 가지: `HeroCampaign` 세 칸, 원정 = 만든 전장을 다 이기면 다른 영웅의 전장 | 원정이 이미 있다 → 장치가 영웅마다 다르게 작용하는 것이 바로 쓰인다 |

**없는 것** (장치에 새로 필요한 것):

- **시간 따라 움직이는 장치.** 주기, 예고, 판정, 연출이 없다. 지금은 모두 가만히 있는 막힘이다.
- **기술 성질 표시.** `SkillDef`에 물·번개·별·먹 표시가 없다. 원정 반응에 필요하다.
- **구역 효과.** 안에 있으면 느려지거나 숨겨지거나 피해를 받는 바닥 면이 없다.
- **투사체가 막힘에 막히는 것.** `Projectile`은 막힘 층을 보지 않는다.
- **무대 바탕 소리.** 환경음 반복이 없다.

**공통 틀 제안** (추천 넷에 모두 필요; 한 파일 한 책임, 수치는 데이터에):

- `scripts/data/stage_hazard_data.gd` (Resource): 기본 필드는 `first_delay`, `period`, `warn_time`, `enemy_damage`, `hero_damage`, `react` (성질 → 반응 표).
  - `LaneStrikeData`: 줄 공격 — 포격선, 기마 돌격.
  - `FieldPatchData`: 번지는·머무는 면 — 들불, 풀숲, 빛 구역.
  - `CoverRuleData`: 막힘이 투사체를 막는지.
  - 나중 변주용 `DriftData`: 흐름 — 물살, 바람, 기울기.
- `scripts/world/stage_hazards.gd` (Node2D, Arena 자식): 목록대로 장치 노드를 만든다. `StageApply.stage`에서 한 줄로 부른다.
- 장치 노드는 하나에 한 파일, 150~250줄: `lane_strike.gd`, `field_patch.gd` 등.
  - 박자와 판정은 순수 계산으로 `RefCounted`에 나눠 시험한다.
- `SkillDef.element: StringName` (`&"water"`, `&"thunder"`, `&"star"`, `&"ink"`): 영웅 `.tres`에 한 줄씩 넣는다.
- 보스 등장·단계 전환 중에는 장치가 쉰다 (`BossFeelData` 전환 1.8초와 맞춘다).

## 3. 전장별 안 (A/B/C)과 추천

각 안의 평가 항목:

- **재미**: 플레이를 실제로 바꾸는가.
- **읽기**: 세로 화면에서 엄지 하나로 읽고 피할 수 있는가.
- **크기**: 지금 코드로 되는가, 새로 얼마나 필요한가.
- **그림·소리**: 새로 필요한 것.

수치는 첫 제안이다. 영웅 체력 85~140, 잡몹 20~40, 중장 140을 기준으로 잡았다.

### 3.1 한산 갑판 (순신) — 축: **선**

지도: 긴 갑판 양쪽 난간에 대포가 줄지어 있고, 위아래에 승강구 쇠살문 둘, 가운데 돛대, 바깥은 불타는 배와 바다.

**A. 포격선 ★추천**

- **어떻게 도나**
  - 12초마다 난간 대포 한 쌍이 갑판을 **가로지르는 줄**(폭 140px)을 붉은 먹선으로 그린다.
  - 북이 세 번 울린다 (예고 1.2초).
  - 그다음 포성과 함께 줄 위 모두를 친다. 적은 60(잡몹 즉사, 중장 40%), 영웅은 10.
- **물결에 따라**
  - 물결 2부터는 줄이 두 개(위·아래)가 된다.
  - 보스 3단계에는 왜군 대장이 "쏘아라!"로 줄을 직접 부른다 (§7 결정 4).
- **재미**: 적을 줄 위로 끌어들이고 나는 빠진다. 줄 하나에 떼가 지워지는 순간이 크다. 순신의 대시(파도격)가 줄을 가로질러 빠지는 맛이 산다.
- **읽기**: 세로 화면에서 **가로줄**은 가장 읽기 쉽다. 엄지를 위나 아래로 조금만 밀면 된다. 줄이 화면 밖이면 화면 가장자리에 붉은 화살표를 보인다.
- **크기**: 작음.
  - 판정은 `EnemyAttack.contains`의 직사각형과 같다.
  - 예고 그리기는 적 돌진 예고를 그리는 코드를 따라 한다.
  - 새로 만들 것은 `LaneStrikeData` + `lane_strike.gd` (~180줄) + 시험.
- **그림·소리**
  - 그림: 대포 불꽃(있는 `cannon` 소품 위에 한 장), 줄을 따라 튀는 나무 조각.
  - 소리: 북 예고(`gugak_buk` 있음), 포성(CC0 하나).

**B. 갑판 기울기**

- **어떻게 도나**
  - 15초마다 3초 동안 배가 한쪽으로 기운다. 화면이 2° 돌고 물결선이 보인다.
  - 모든 것이 낮은 쪽으로 미끄러진다. 잡몹은 120px/s, 영웅은 40px/s.
  - 난간 틈(지도에 2~3곳)으로 밀려난 잡몹은 바다에 빠진다 (즉사).
- **재미**: 밀치기(해룡참·반격)의 값어치가 커진다 ("바다로 떨어뜨리기"). 하데스 벽 부딪힘 배율과 같은 원리다.
- **읽기**: 보통. 화면이 돌면 손가락 조작과 어긋나 보일 수 있다. 영웅 미끄러짐은 작게 해야 한다. 멀미 걱정이 있다.
- **크기**: 보통.
  - 적 움직임에 바깥 흐름을 더하는 연결이 필요하다 (`enemy.gd` 한두 줄 연결).
  - 영웅 움직임도 마찬가지다.
  - 난간 틈을 `map_blockers`에서 빼야 하므로 지도 그림을 고쳐야 한다.
- **그림·소리**: 나무 삐걱임, 파도 부딪힘. 지도 난간 틈.
- 명량의 "물살"과 원리가 같다. 명량 변주로 미루면 좋다 (§5).

**C. 화약통 (+ 승강구) — A의 짝으로 작게**

- **화약통**: 부서지는 것 두 번째 종류. 무대에 2개, 30초마다 다시 생긴다. 치면 1.0초 뒤 반지름 160 폭발. 적 50, 영웅 8. 근처 화약통으로 번진다.
- **승강구 (선택)**: 물결의 일부가 승강구 두 곳에서만 올라온다 (예고 0.6초). 떼가 오는 방향이 읽힌다.
- **재미**: 적을 통 옆으로 모아 터뜨린다. 포격선과 함께 쓰면 "줄 + 점"이 된다.
- **읽기**: 통은 크고 빨갛다. 불붙은 심지와 째깍 소리로 1초 예고.
- **크기**: 작음.
  - `BreakableData`를 목록으로 넓히고 `on_break` 효과(폭발 반지름·피해)를 더한다.
  - 승강구는 `WaveSetData`에 `spawn_points`를 더하고 지도 좌표를 넣는다.
- **그림·소리**: 화약통 그림 한 장(GPT), 폭발은 있는 먹 터짐을 쓴다. 심지 소리와 폭발음 (CC0).

**한산 추천: A 포격선 + C 화약통.**

- 둘 다 "끌어들여 쓸기"라 순신의 대시와 쓸기에 맞는다.
- 줄과 점이라 겹치지 않는다.
- 공통 틀을 만드는 첫 무대로도 가장 쉽다.

### 3.2 만주 벌판 (광개토) — 축: **번지는 면**

지도: 넓은 흙 평원, 수레바퀴 자국, 모닥불 자리, 바위·천막, 가장자리 마른 풀.

**A. 망령 기마 돌격로**

- **어떻게 도나**
  - 14초마다 지평선 쪽(화면 위)에서 흙먼지가 일고 말발굽 소리가 커진다 (예고 1.5초).
  - 넓은 줄(폭 200px)을 따라 망령 기병 떼가 위에서 아래로 **0.8초 동안 훑고 지나간다**.
  - 줄 안의 적은 30 피해를 받고, 훑는 방향으로 끌려가 줄 끝에 **한 무더기로 모인다**. 영웅은 12 피해에 밀려난다.
- **재미**: 떼를 한곳에 모아 준다 → 광개토의 낙뢰 사슬과 정복자의 일격에 딱 맞는 먹잇감.
- **읽기**: 세로 줄이라 좌우로 비키면 된다. 다만 한산 포격선과 같은 "줄 장치"여서 두 무대가 닮아진다.
- **크기**: 작음. 한산의 `LaneStrike`에 "훑기 + 끌고 가기" 선택을 더하면 된다.
- **그림·소리**: 망령 기병 실루엣(호박색 도깨비불 + 흙먼지, 반투명 — 한 장을 늘어놓기), 말발굽 북소리.

**B. 모래바람 방향**

- **어떻게 도나**
  - 20초마다 바람 방향이 바뀌고 8초 동안 분다. 풀이 눕고 먼지 줄무늬가 보인다.
  - 바람 방향으로 가는 화살·검기·유성은 1.3배 빨라지고 멀리 간다. 맞바람이면 0.75배다.
  - 바람을 안고 걷는 적은 느려진다.
- **재미**: 원거리 싸움의 맛이 바뀐다. 거란 궁수가 바람을 탄다.
- **읽기**: 보통. 바람은 화면 전체 무늬라 방향은 읽히지만, 효과(빠르기 배율)는 몸으로 느껴야 한다. 한 손 조작에는 방해가 적다.
- **크기**: 보통. 투사체와 적 움직임 양쪽에 연결이 필요하다 (`Projectile`, `enemy.gd` 한 줄씩).
- **그림·소리**: 풀 눕는 무늬(코드로 그림), 바람 소리 반복 (CC0).

**C. 들불 ★추천**

- **어떻게 도나**
  - 지도 가장자리 마른 풀밭이 불탈 수 있는 면 5~7곳이다 (지도 좌표).
  - 다음이 닿으면 **불이 붙는다**: 번개(광개토)·유성(세종), 화약·횃불을 든 적의 공격.
  - 불은 3초마다 이웃 풀로 한 칸씩 번지다가 10초 뒤 꺼진다. 탄 자리는 그 판 동안 다시 붙지 않는다.
  - 불 위에 선 것은 초당 피해를 받는다. 적 15/s, 영웅 4/s. 적은 불을 피해 돌아간다.
- **재미**: 전장이 판 안에서 변한다. 불길로 벽을 세워 떼를 가르거나, 떼가 몰린 풀밭에 번개를 떨어뜨린다.
- **읽기**: 바닥의 불은 붉고 밝아 가장 잘 읽힌다 (우리 무대는 어두운 바탕 + 밝은 효과로 맞춰 두었다). 번지는 다음 칸은 연기로 1초 미리 보인다.
- **크기**: 보통.
  - `FieldPatchData`(면 목록, 번지기 그래프) + `field_patch.gd` (~220줄).
  - 불 피해 구역은 `Area2D` 하나에 칸 여럿.
  - 적이 피하는 것은 기존 막힘 돌아가기를 "약한 막힘"으로 넓힌다.
  - `SkillDef.element` 필요.
- **그림·소리**: 마른 풀 면(지도에 이미 그려져 있다 — 좌표만 뽑는다), 불길 띠 한 장 + 탄 자국 한 장, 불 타닥 반복과 붙는 소리 (CC0).

**만주 추천: C 들불.**

- 광개토(번개)의 홈 전장이라 "내가 전장에 불을 지른다"는 정체성이 생긴다.
- 원정 반응이 가장 풍부하다 (§4). 순신은 끄고, 세종은 멀리서 붙이고, 사임당은 조심한다.
- A 기마 돌격은 한산과 겹치므로 광개토의 둘째·셋째 전장 변주로 남긴다 (§5).

### 3.3 경복궁 (세종) — 축: **건물**

지도: 돌 깔린 넓은 뜰. 가운데 어도(임금 길), 양쪽에 품계석 두 줄, 위에 근정전 계단, 아래 문, 석등 둘.

**A. 문 여닫기**

- **어떻게 도나**
  - 물결마다 아래 문과 옆 행각 문 중 1~2곳만 열린다. 열릴 문은 문짝이 빛나며 0.8초 전에 예고한다.
  - 적은 열린 문으로만 줄지어 들어온다.
  - 물결 사이에 문이 바뀐다.
- **재미**: 좁은 입구 앞에 세종의 정음진과 유성을 깔아 두는 "자리 잡기" 맛. 떼가 줄을 선다 (디아블로류 복도 원리).
- **읽기**: 좋다. 문 위치가 늘 같다.
- **크기**: 작음.
  - `WaveSetData.spawn_points` (한산 승강구와 같은 기능)에 물결별 문 고르기를 더한다.
  - 문 그림 열림/닫힘 두 장.
- **그림·소리**: 문짝 열림 그림(GPT 두 장), 문 삐걱 소리, 징 한 번 (`gugak` 계열 있음).

**B. 품계석·기둥 엄폐 ★추천**

- **어떻게 도나**
  - 품계석과 석등이 **곧게 날아가는 투사체를 막는다**. 지금도 걸음은 막는다 (`map_blockers` 57px 원 열두 개 이상).
  - 막는 투사체: 여진 궁수의 화살, 왜군 조총, 순신 해일검기·사방 검기.
  - 위에서 떨어지는 것(유성·낙뢰), 바닥에 그리는 것(정음진 글자, 화폭)은 막지 않는다.
  - 돌은 투사체를 막을 때마다 금이 간다. 세 번째 금에서 부서지고 그 판 동안 사라진다. 그래서 엄폐가 영원하지 않다.
- **재미**
  - 여진 궁수와 숨바꼭질을 한다. 돌 뒤에 숨어 다가가고, 궁수가 쏘는 박자 사이에 나간다.
  - 세종은 위에서 떨어지는 기술이 많아 **돌 너머를 칠 수 있는 유일한 영웅** → 홈 전장의 이점이 생긴다.
  - 광개토의 벽력돌파는 돌을 부수며 지나간다 (§4).
- **읽기**: 좋다. 돌이 이미 지도에 두 줄로 서 있다. 막힐 때 튀는 돌가루와 금 간 모양으로 상태를 보인다.
- **크기**: 작음~보통.
  - `CoverRuleData` (어떤 막힘이 무엇을 막는지, 몇 번에 부서지는지).
  - `Projectile`이 5번 층(막힘)을 보게 하는 연결 한 줄.
  - 막힘 원을 하나씩 없애는 `Obstacles.remove_at`.
  - 금 그림은 코드로 먹선 몇 획.
- **그림·소리**: 부서진 품계석(GPT 한 장, 기존 `pillar_broken` 그림과 맞춤), 돌 맞는 딱 소리와 부서지는 소리 (CC0).

**C. 석등 밝히기 (빛 구역)**

- **어떻게 도나**
  - 석등 넷(지도 둘 + 소품 둘)을 영웅이 치면 불이 켜진다.
  - 켜진 석등 둘레(반지름 240)는 망령이 약해지는 빛 구역이 된다. 받는 피해 +30%, 망령 테두리 흐려짐.
  - 20초 뒤 꺼진다. 망령 정예는 석등을 일부러 끈다.
- **재미**: 싸울 자리를 내가 고른다 (디아블로류 사당 원리). 망령 설정과도 맞는다.
- **읽기**: 좋다. `LightPools`가 이미 빛 웅덩이를 그린다.
- **크기**: 작음. `StageLook`의 소품 빛을 켜고 끌 수 있게 하고, `FieldPatch`의 "안에 있으면 약해짐" 효과를 더한다.
- **그림·소리**: 켜진 석등 한 장, 불 붙는 소리, 풍경(바람 종) 바탕 소리.
- 노량(밤 전장)의 변주와도 이어진다 (§5).

**경복궁 추천: B 엄폐** (+ 여유가 되면 A 문을 물결 장치로).

- 궁궐은 "건물이 싸움을 막는 곳"이라는 정체성.
- 원정 때 영웅마다 반응이 가장 뚜렷하다. 세종은 넘겨 치고, 순신은 검기가 막혀 돌아가야 하고, 광개토는 부순다.

### 3.4 초충도 (사임당) — 축: **숨기**

지도: 빈 한지 가운데, 가장자리에 맨드라미·가지·오이 덩굴·수박·풀꽃·바위.

**A. 풀숲 숨기 ★추천**

- **어떻게 도나**
  - 한지 위에 먹으로 그린 **풀숲 면** 4~6곳 (반지름 140~200, 지도 좌표).
  - **영웅이 들어가면**
    - 영웅이 반투명해진다.
    - 원거리 적은 겨냥을 놓친다 (쏘기 멈춤). 근접 적은 마지막 본 자리로 간다.
    - 풀숲에서 나오며 친 첫 공격은 **기습** (피해 ×1.5, 숫자 금빛).
  - **적이 들어가면**
    - 적은 몸 대신 흔들리는 풀잎과 도깨비불 끝만 보인다. **완전히 사라지지 않는다** (읽기 때문).
    - 방아깨비는 풀숲에서 튀어나오며 덮친다 (초충도 적의 버릇 하나).
- **재미**: 들어가 숨고 나오며 친다. 리듬이 생긴다. 사임당이 그린 그림 속이라는 설정과 맞는다.
- **읽기**: 보통. 숨은 적은 모바일에서 위험하다. 그래서 다음을 지킨다.
  - 적은 늘 흐린 실루엣으로 남긴다.
  - 풀숲은 크고 수가 적고, 위치가 늘 같다 (지도에 그려진 것).
  - 기습 금빛으로 보상을 확실히 보인다.
- **크기**: 보통.
  - `FieldPatchData`(숨기 효과).
  - 적 겨냥에 "영웅이 숨었나?" 확인 연결 (`enemy_attack`이나 적 인지 쪽 한 줄).
  - 적 그리기 투명도 (`enemy_art` 쪽 연결 하나).
  - 기습 배율은 `SkillContext.hit` 쪽.
- **그림·소리**: 풀숲 면(지도에 그려 넣는다 — 지도 다시 그리기), 흔들리는 풀잎(코드 먹선), 풀 스치는 소리와 풀벌레 바탕 소리 (CC0).

**B. 곤충 떼 지나가기**

- **어떻게 도나**
  - 18초마다 종이 한쪽에서 벌레 떼(나비·벌, 그림 속 생물)가 일어나 반대쪽으로 날아간다. 넓은 띠, 2초.
  - 띠 안에서 적은 홀려서 1.5초 멈춘다. 영웅은 시야를 조금 가린다 (피해 없음).
  - 꽃(맨드라미)을 치면 그 자리로 떼를 불러올 수 있다.
- **재미**: 떼를 내 편으로 쓰는 맛. 사임당의 풀벌레 부르기와 결이 같다.
- **읽기**: 보통. 시야 가림은 모바일에서 불편하다 → 반투명하게, 화면의 1/4 이하로.
- **크기**: 보통. `LaneStrike`의 띠에 "멈춤" 효과를 붙이고, 꽃은 부서지는 것 종류로 둔다.
- **그림·소리**: 나비·벌 떼 그림(시트 한 장), 날갯짓 소리.

**C. 화폭이 말린다 (땅 모양 바뀜)**

- **어떻게 도나**
  - 물결마다 두루마리가 위나 아래에서 말려 들어와 걸을 수 있는 땅이 15%씩 줄었다 늘었다 한다.
  - 말려 들어오는 가장자리는 1.0초 예고 후 그 자리의 적을 말아 넣는다. 잡몹은 즉사, 영웅은 밀려난다.
- **재미**: 땅 모양이 판 안에서 바뀐다 (하데스의 "구역마다 다른 땅 모양"을 한 무대 안에서).
- **읽기**: 좋다. 가장자리가 움직이는 것은 화면에서 뚜렷하다.
- **크기**: 보통~큼. `Arena.rect`와 카메라 묶기, 막힘·지도 그림 자르기를 판 중에 바꿔야 한다. 스폰 영역과 부서지는 것 자리도 따라 바뀐다.
- **그림·소리**: 두루마리 끝 그림(GPT 한 장), 종이 말리는 소리.

**초충도 추천: A 풀숲 숨기.**

- 다른 세 전장(선·면·건물)과 축이 겹치지 않는다.
- 그림 세계라는 설정이 가장 잘 산다.
- C 말림은 사임당 셋째 전장의 변주로 남긴다 (§5).

## 4. 원정 — 같은 장치가 영웅마다 다르게

**반응을 만드는 두 가지.**

- **기술 성질** (`SkillDef.element`, 새 필드):
  - 순신 = 물
  - 광개토 = 번개
  - 세종 = 별 (위에서 떨어지는 것 많음)
  - 사임당 = 먹 (바닥에 그리는 것, 부르는 것)
- **영웅 체급** (지금 `HeroData` 수치로 이미 갈린다):
  - 광개토는 무겁고 가깝다.
  - 세종은 멀고 가볍다 (체력 85).
  - 사임당은 부른다.
  - 순신은 빠르게 가로지른다.

반응은 장치 데이터의 `react` 표에만 적는다. 영웅 코드는 건드리지 않는다.

| 장치 \ 영웅 | 순신 (물·가로지르기) | 광개토 (번개·무거움) | 세종 (별·멀리서) | 사임당 (먹·부르기) |
|---|---|---|---|---|
| **한산 포격선** | 홈. 대시로 줄을 가로질러 빠지며 적을 줄에 남긴다 | 느려서 줄을 피하기 어렵다 → 대신 기절·내려찍기로 **적을 줄 위에 붙잡아 둔다** | 멀리 서 있어 줄에 덜 걸린다. **해시계 멈춤이 포격 박자도 멈춘다** (예고 중이면 멈춘 채로 → 시간 벌기) | **화폭이 적을 줄 위에 가둔다** → 가장 큰 쓸기 |
| **한산 화약통** | 해일검기가 통을 적시면 **터지지 않는다** (실수 주의, 또는 아군 쪽 통 끄기) | 낙뢰 사슬이 통에서 통으로 **연쇄 폭발** | 유성으로 멀리서 터뜨린다 | 풀벌레가 통을 건드려 터뜨린다 |
| **만주 들불** | 해일검기가 **불을 끄고 길을 낸다** (꺼진 자리는 김이 오르고 다시 안 붙는다) → 들불이 순신에게는 위험, 대신 길을 고를 수 있다 | 홈. 낙뢰·벽력돌파가 **불을 붙인다** | 유성이 떨어진 자리에 불씨 → 멀리서 붙인다 | 풀벌레가 불에 탄다 (부른 것이 일찍 사라짐) → **발묵 먹 웅덩이는 불이 넘지 못한다** (불길을 막는 벽) |
| **경복궁 엄폐** | **해일검기·사방 검기가 돌에 막힌다** → 돌 사이 틈으로 쏘거나 돌을 깨야 한다. 가장 어려운 원정 | **벽력돌파가 돌을 부수며 지나간다** (한 번에 금 3개) → 엄폐를 없애 궁수를 드러낸다 | 홈. 위에서 떨어지는 기술은 돌을 넘는다 | 화폭·발묵은 바닥이라 막히지 않는다. 풀벌레는 돌을 돌아간다 |
| **초충도 풀숲** | 대시로 풀숲을 가로지르면 풀이 흔들려 **숨은 적이 드러난다** | **번개가 풀숲을 태운다** (그 판 동안 숨을 곳이 줄어든다 — 들불 원리 재사용) | **성좌진 별빛이 숨은 적을 드러낸다** (반지름 안) | 홈. 풀벌레가 풀숲에 숨어 있다가 기습 |

**이 표가 원정을 바꾸는 방식.**

- 같은 전장이 영웅마다 **쉬움과 어려움의 자리가 다르다**.
  - 순신은 경복궁이 가장 어렵다 (검기가 막힌다).
  - 광개토는 한산 포격선이 가장 어렵다 (느리다).
  - 세종은 들불이 쉽다.
  - 사임당은 들불이 어렵다 (부른 것이 탄다).
- 그래서 원정 순서와 강화 고르기가 달라진다. 예: 순신으로 경복궁에 가면 관통이나 넘겨 치기 강화의 값어치가 오른다.
- 이미 알려진 문제가 하나 있다 (stage-bosses 인계 1번). 남의 전장 보스 체력이 그 전장 주인 영웅 기준이라 원정 때 길어진다. 장치와 함께 **원정 보스 체력 배율**을 정해야 한다 (§7).

## 5. 영웅당 세 전장 — 장치 변주

**원칙.**

- **축은 그대로** 둔다. 순신은 줄과 물, 세종은 건물, 사임당은 숨기와 그림, 광개토는 번지는 면과 힘.
- 전장마다 **변주 하나**(같은 장치의 모양을 바꾼 것)와 **새 겹 하나**(작은 둘째 장치)를 더한다.
- 그래서 같은 영웅의 세 전장은 "같은 집안의 다른 방"처럼 느껴지고, 네 영웅의 전장끼리는 축부터 다르다.
- 같은 장치 코드(`LaneStrike`, `FieldPatch`, `CoverRule`, `Drift`)를 데이터로 바꿔 끼우므로 **코드는 거의 늘지 않는다**.

| 영웅 | 첫 전장 | 둘째 | 셋째 | 변주 요령 |
|---|---|---|---|---|
| 순신 | **한산** — 포격선 + 화약통 (낮, 넓은 갑판) | **명량** — **거꾸로 도는 물살**: 좁은 물목, 바다 위 작은 판옥선 갑판들이 이어진 땅. 물살 띠가 한 방향으로 흘러 적을 실어 가다가 25초마다 방향이 뒤집힌다 (`DriftData`: 갑판 기울기 B를 여기로). 포격선은 하나로 줄인다 | **노량** — **밤의 불배**: 어두운 바다, 불붙은 배 조각이 떠내려와 빛 구역과 불 면을 만든다 (`LightPools` + 들불 `FieldPatch` 재사용). 포격선은 양쪽 난간에서 엇갈려 온다 | 줄 → 흐름 → 불과 어둠. 마지막 전장의 무게(어둠·불빛)는 색과 소리로. **역사 묘사의 톤은 사용자 확인 필요** |
| 세종 | **경복궁** — 품계석 엄폐 (넓은 뜰) | **창덕궁** — **연못과 다리**: 후원 연못이 걸음을 막고 투사체는 통과하는 땅 (엄폐의 반대). 좁은 다리와 정자가 길목이 된다. 새 겹: 석등 빛 구역 C | **동궁전** — **여닫는 문**: 실내 전각 여러 칸, 칸 사이 문이 물결마다 여닫힌다 (문 A). 좁은 방 싸움 | 건물이 막는 것을 바꾼다: 투사체 → 걸음 → 공간. 세 전장 모두 같은 `CoverRule`·`spawn_points` |
| 사임당 | **초충도 첫 폭** — 풀숲 숨기 | **둘째 폭** — **곤충 떼** B + 덩굴 풀숲(오이·가지 덩굴이 길쭉한 띠 모양 풀숲) | **셋째 폭** — **화폭이 말린다** C: 땅이 물결마다 줄고 는다 + 풀숲 | 숨기 → 떼 → 땅. 폭마다 그 그림의 주인공 식물이 장치가 된다. **어느 폭을 쓸지는 작품 확인 후** (초충도 폭 수·작품명은 scenario.md에서도 확인 대기) |
| 광개토 | **만주** — 들불 | **미정 1** (후보 예: 성 공격 — 성벽·성문을 **부수는** 전장. 무거운 영웅의 정체성. 기마 돌격 A를 성문 앞 길로) | **미정 2** (후보 예: 언 강 — 얼음 면이 미끄럽고, 무거운 것이 오래 서 있으면 깨져 빠진다. 눈보라는 **시야를 가리지 않고** 바람 B로만) | 번지는 면(불 → 얼음) + 힘(부수기). **두 전장의 역사 배경은 미정이라 여기서는 장치 후보만** |

**변주할 때 지킬 것.**

- **한 전장의 주인공 장치는 하나**다. 둘째 겹은 첫 전장 장치보다 작게 둔다 (주기 두 배, 피해 절반).
- 전장 순서대로 장치가 하나씩 쌓이지 않게 한다. 셋째 전장에서 장치 셋이 동시에 돌면 세로 화면이 읽히지 않는다.
- **눈보라·어둠처럼 시야를 가리는 장치는 모바일에서 피한다.** 쓴다면 화면 가장자리만 흐리게 해서, 영웅 둘레 반지름 300px은 늘 맑게 둔다.

| 6 | 무대 바탕 소리 넷 | `StageTheme.ambience` + 음악 감독 한 줄 | 파도·바람·풍경·풀벌레 (CC0) | 크기: 반복 소리 4개 × 약 200KB (줄이기 아님, 원본 그대로) |

- 합계: 새 파일 약 10개 (모두 250줄 이하), 고칠 파일 약 8개 (연결 1~5줄씩).
- 새 그림 8~12장 (GPT, 기존 수묵 화풍). 유료 3D 작업은 필요 없다.
- 소리 6~10개 (CC0만).
- **시험.**
  - 장치마다 순수 계산(박자·판정·번지기)은 `RefCounted` 단위 시험으로.
  - 실제 장면 시험 하나: 장치가 적을 치고, 예고가 판정보다 먼저 보이는지.
  - 무대 보스 시뮬과 성장 시뮬은 장치를 켠 채로 다시 잰다. 장치가 적을 지우므로 보스 도착이 빨라진다 → 물결 수치를 다시 맞춘다.
- **화면 확인 도구.** `tools/shots/burst_strip.gd`처럼 장치 한 번의 연속 장면 띠를 찍는다 (`hazard_strip.gd`). 사용자에게 전후 비교로 보인다.

## 7. 사용자가 정할 것

1. **중립 원칙 — 영웅도 장치에 맞나?**
   - 추천: 맞되 작게 (잡몹 한 대 정도, 영웅 체력의 7~10%). 하데스처럼 "조심할 것이자 무기"가 된다.
   - 영웅이 안 맞으면 장치가 그냥 공짜 공격이 되어 피하는 재미가 사라진다.
2. **무대당 장치 수.** 추천: 주인공 장치 하나로 시작하고, 한산만 화약통을 작게 더한다. 둘째 겹은 둘째·셋째 전장 변주로 아낀다.
3. **추천 넷 그대로?** 한산 포격선, 만주 들불, 경복궁 엄폐, 초충도 풀숲. 바꾸고 싶은 전장이 있으면 그 전장의 A/B/C에서 고른다.
4. **보스가 장치를 쓰나?**
   - 추천: 3단계 군령 하나로 쓴다. 왜군 대장 "쏘아라!" → 포격선, 거란 부족장 "불 질러라!" → 들불, 여진 추장 "돌을 부숴라!" → 엄폐 무너뜨리기, 개구리 장군 → 풀숲에서 혀.
   - 보스 군령 데이터(`boss_phase_data`)에 장치 부르기 한 칸을 더하면 된다.
5. **원정 보스 체력.** 남의 전장 보스가 길어지는 문제 (stage-bosses 인계 1번). 영웅별 배율 한 줄로 맞출지 정해야 한다.
6. **셋째 전장들 배경 확인.** 명량·노량의 묘사 톤, 창덕궁·동궁전의 구성, 초충도 폭 선택, 광개토 둘째·셋째 전장. 모두 세계관 미확정 → 정하면 그때 `scenario.md`에 넣는다.
