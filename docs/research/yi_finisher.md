## 2. 왜 순신 4타만 어색했나

박자 자체는 순신이 가장 빨랐다. 어색함은 아래 세 가지에서 왔다.

1. **피해와 그림이 어긋났다.**
   - 해룡참은 누르는 순간 휘감기가 시작돼 피해가 나간다 (0.16초에 한 바퀴).
   - 뛰어 내려찍기는 0.25초 뒤에야 땅을 친다.
   - 그래서 몹이 먼저 맞고 날아간 뒤에 영웅이 내려온다. "연계 타이밍이 어색하다"의 직접 원인이다.
2. **3타에서 4타로 자세가 튀었다 (1.67).**
   - 3타는 땅에서 옆으로 베고, 4타 첫 칸은 뛰어오르는 준비 자세다.
   - 사임당(0.51)은 1~4타가 같은 동작 묶음이라 끊김이 없다.
3. **무겁고 긴 동작이었다.**
   - 몸 기울기 164°의 뛰어오르기 0.4초, 그 뒤 다음 1타까지 0.42초가 걸렸다.
   - "쾌검"(빠른 칼)인 순신과 반대 성격이다.
   - 광개토는 찌르고 빨리 거둔다 (닿음 0.167초).
   - 사임당은 휘두르는 도중에 피해가 차르륵 들어간다 (누른 뒤 0.145~0.33초).
   - 둘 다 "치는 순간"과 "그림"이 맞는다.

## 3. 세 가지 안

| 안 | 예상 박자 | 동작 | 균형 |
|---|---|---|---|
| **(가) 돌려 베기로 교체** (선택, 적용) | 4타 → 다음 1타 0.25초, 한 바퀴 1.27초 | 받아 둔 `web_weaponcombo` (칼끝 호 412°, 받아 둔 것 중 가장 큼), 크레딧 0 | 휘감기 피해·범위는 그대로. 다음 1타가 0.17초 빨라 초당 피해가 는다 (5절) |
| (나) 내려찍기 유지, 준비 구간 자르기 | 시작 칸을 4로 당기면 그림 닿음 0.05초, 잠금 약 0.2초 | 그대로 | (가)와 비슷. 3→4 자세 튐(1.67)과 무거운 성격은 남는다 |
| (다) 빠른 2~3연 베기 | 0.3~0.4초에 여러 번 | 받아 둔 것 중 맞는 것이 약함 (`triplecomboattack` 기울기 37~53°) | 해룡참을 여러 번 맞히는 새 판정이 필요 (코드 추가) |

## 4. 교체 (적용한 값)

**구간**: `web_weaponcombo` 1.87~2.47초
- 7칸, 24fps, 닿는 칸 4.
- 칸 시각: 1.87 / 1.97 / 2.07 / 2.13 / 2.20 / 2.33 / 2.47.
- 닿는 칸 앞뒤로 고르게 펼쳐, 닿고 서지 않고 지나간다 (#124와 같은 원칙).
- 칸 사이 실루엣 변화: 0.41 / 0.40 / 0.32 / 0.42 / **0.53** / 0.41. 닿은 뒤가 가장 크다.

**시작 칸**: `cast_lead` 0.08
- 닿기 0.08초 앞 칸(2)부터 튼다.
- 누르는 순간 나가는 휘감기 피해와 칼이 0.083초 안에 맞는다.

**마무리 잠금**: `kit.finisher_recover` 0.12
- 그림 닿음(0.083초) 바로 뒤까지만 잠근다 (예전엔 동작 전체 0.40초).
- 그래서 다음 1타가 일찍 이어진다.

**3타 → 4타 자세**
- 받아 둔 구간 어디서 시작해도 3타 끝 자세와 1.2~1.37만큼 다르다 (스캔으로 1.40~2.20초를 다 쟀다).
- 그래서 이미 있는 섞기로 메운다: 3D 바꿈 섞기 0.1초, 2D 앞 칸 겹침 0.08초.
- 차이는 1.67에서 1.28로 줄었다.

**검기·판정·여러 번 맞힘**
- 그대로 해룡참의 휘감기를 쓴다.
- 휘감기는 누르는 순간 시작되고, 새 닿는 칸이 그 안(0.083초)에 온다.
