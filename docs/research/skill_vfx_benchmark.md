# 기술 연출 벤치마크 (2026-11-22)

질문: "스킬이 유치한 건, 그냥 그림 땡한 건 어떻게 개선해야 돼? 벤치마크 해 와."
기준: `feat/skill-staging` a7d4642 (PR #38: 조각 등장·휘감아 베기·해시계 바늘·맞은 자리 자국, 514/514). 이 문서는 조사와 제안이다. 구현은 사용자가 고른 뒤에 한다.

## 0. 결론 먼저

- **"유치해 보이는" 원인은 그림의 질보다 층 수와 시간이다.** 잘 만든 기술 이펙트는 그림 한 장이 아니라 5~7개 층(예고·본체·충격·잔상·지면 자국·빛·화면 반응)이 100~600ms 안에 차례로 나왔다 사라진다. PR #38 전의 우리 기술은 대부분 **본체 1층 + 입자**였다. 그래서 "그림 땡"으로 보였다.
- **본체 그림이 멈춰 있는 것이 두 번째 원인이다.** 디아블로 3는 그림 몇 장을 **흘리고(UV 흘리기) 갉아 내서(알파 침식)** 살아 있게 만든다. 우리는 PR #38로 "등장"(조각)과 "퇴장"(먹 번짐)은 생겼지만, 떠 있는 동안 그림 속이 **움직이지 않는다**. 물이 흐르지 않고 불이 일렁이지 않는다. 다음으로 고칠 가장 큰 구멍이다.
- **판정과 그림 크기가 안 맞는 기술이 있다** (롤의 첫 번째 규칙). 해시계는 그림 반지름 200px인데 실제 판정은 300px이다. 매화·화폭(최대 충전)도 그림이 판정보다 작다. "맞을 것 같지 않은데 맞는" 느낌이 가벼움을 만든다.
- **지금 방식(GPT 정지 그림 + 셰이더·입자)으로 갈 수 있는 선은 "디아블로 3·롤 수준의 2D 연출"까지다.** 그 위(하데스처럼 손으로 그린 프레임 애니, 유체처럼 출렁이는 물·불)는 프레임 시트가 있어야 한다.
- **추천 순서 (5장에 비용)**: ① 그림 흘리기·일렁임 셰이더 → ② 판정 크기 맞추기 → ③ 큰 기술 컷인(던파식, 붓글씨 이름) → ④ 국악 소리 층 → ⑤ 획 마스크로 "그려지듯" 등장 → ⑥ 프레임 시트(외주·도구, 나중).

## 2. 게임별: 이펙트 한 개의 층 구성

| 게임 | 예고 | 본체 | 충격 | 잔상 | 지면 자국 | 빛 | 화면 반응 | 그림을 살리는 기법 |
|---|---|---|---|---|---|---|---|---|
| **하데스** [관찰] | 기운 모임·바닥 원 (100~300ms) | 손그림 프레임 애니 (대개 8~16장, 60~200ms) | 하얀 번쩍 + 터짐 프레임 | 연기·불씨가 흩어짐 | 금 간 바닥·불탄 자국 (1~2초) | 은혜 신마다 색 빛 (더하기) | 짧은 멈춤, 작은 흔들림, 맞은 적 하얗게 | 프레임 애니가 중심, 그 위에 입자와 빛. 은혜마다 색·모양 언어 통일 (제우스 = 번개 가지, 포세이돈 = 물결 밀기) |
| **롤** [문서+관찰] | 판정 범위 표시가 그림과 **정확히 같은 크기** | 메시 + 흘리는 텍스처 | 맞은 적마다 작은 충격 | 짧게 (가독성 우선) | 지속 장판만 남김 | 아군·적군 색 규칙 | 거의 없음 (경쟁 게임) | UV 흘리기·침식. "시각적 무게 = 게임상 무게" |
| **던파** [관찰] | 큰 기술은 **컷인** (캐릭터 그림 + 기술 이름, 200~500ms 정지 또는 느림) | 프레임 애니 이펙트 | 타격마다 번쩍 + 타격음 겹 | 검기·궤적 | 금 간 바닥 | 강한 더하기 빛 | 흔들림, 역경직, 슬로우 | 프레임 애니 + 스케일 튐 + 컷인으로 "필살기" 신호 |
| **디아블로 2 레저렉션** [관찰] | 거의 없음 (즉발) | 원작 2D 프레임을 3D로 다시 그림 | 맞은 적 번쩍·피 튐 | 불씨·연기 | 얼음·불 장판 | 광원 (주변 밝힘) | 거의 없음 | 3D 입자 + 광원. 원작 1장 스프라이트는 짧은 프레임 애니 |
| **디아블로 3** [문서] | 짧음 | 잡음 여러 겹 흘림 × 마스크 | 터짐 | 침식으로 사라짐 | 장판 | 블렌드-더하기 (흰색으로 안 날아가게) | 흔들림 | **그림 몇 장으로 수많은 효과** (우리와 가장 가까움) |
| **뱀서·Brotato·Archero** [관찰] | 없음 | 작은 스프라이트 또는 2~4프레임 | 맞은 적 하얗게 번쩍 + 숫자 | 거의 없음 | 거의 없음 | 약함 | 거의 없음 | **개수**로 화려함. 한 개는 단순, 대신 크기·개수가 성장으로 늘어남. 저사양 기준 |

### 층별 시간 (한 번 쓰는 범위기 기준, [추정])

| 층 | 시간 | 하는 일 |
|---|---|---|
| 예고 | 0~300ms (즉발기는 0~80ms) | "곧 터진다", 판정 범위 |
| 본체 등장 | 60~150ms | 0에서 커지며 나타남 (튀어나왔다 자리 잡기) |
| 충격 | 30~80ms | 하얀 번쩍, 멈춤, 흔들림, 진동 |
| 본체 유지 | 100~300ms | 그림 속이 **움직인다** (흐름·일렁임) |
| 잔상·퇴장 | 200~500ms | 침식·흩어짐·연기 |
| 지면 자국 | 1~3초 | 무게가 남는다 |
| 소리 | 시전음 → 타격음(맞을 때마다) → 꼬리음 | 층마다 따로 |

## 3. 그림 한 장을 "살아 있게" 만드는 기법

| 기법 | 무엇 | 우리 상태 | 비용 |
|---|---|---|---|
| UV 흘리기 (flow) | 그림 속을 한 방향으로 흐르게 (물결이 밀려감) | **없음** | 셰이더 한 개, 반나절 |
| 잡음 왜곡 (일렁임) | 잡음으로 UV를 조금씩 흔들어 불·물이 살아 있게 | **없음** | 위와 같은 셰이더 |
| 알파 침식 (dissolve) | 잡음 순서대로 갉아 사라짐, 가장자리 먹색 | 있음 (`ink_decal.gdshader`) | — |
| 마스크로 그려지듯 등장 | 붓 획 모양 마스크를 따라 나타남 | 반쯤 (PR #38 부채꼴 조각) | 셰이더, 반나절~하루 |
| 조각·시간차 | 부분마다 등장 시각이 다름 | 있음 (PR #38) | — |
| 스케일 튐 | 커졌다 자리 잡음 | 있음 (조각 튐, PR #38) | — |
| 잔상 | 지난 위치 복사본 | 해일검기만 (PR #38) | — |
| 입자 | 물방울·불똥·꽃잎·글자 | 있음 (`SkillVfx`) | — |
| 프레임 애니 | 그림 여러 장 차례로 | **없음** | 그림 필요 (6장) |
| 색 번쩍 (맞은 적) | 맞은 적 하얗게·빨갛게 | 적 쪽은 타격감 세션 담당 | — |

## 5. 한계: 지금 방식으로 어디까지, 무엇부터 그림이 필요한가

| 단계 | 지금 방식으로 됨? | 설명 |
|---|---|---|
| 층 구성 (예고·충격·잔상·자국·빛·화면) | **된다** | PR #38로 대부분 채움 |
| 그림 속 흐름·일렁임 | **된다** | 디아블로 3식 셰이더. 정지 그림이 "물"처럼 보이게 하는 핵심 |
| 그려지듯 등장 (붓 획 마스크) | **된다** | 마스크는 절차적으로 (각도·거리·잡음) |
| 컷인 | **된다** | 영웅 카드 그림 재사용, 기술 이름은 덕온공주체 (글자 확인 필요) |
| 출렁이며 모양이 바뀌는 물·불 (파도가 부서지는 순간) | **안 된다** | 정지 그림을 아무리 흔들어도 "모양이 바뀌는" 움직임은 못 만든다. 프레임 시트(6~12장)가 필요 |
| 캐릭터가 그림과 맞물리는 동작 (용을 타고 베기 등) | **안 된다** | 영웅 동작 클립 + 프레임 애니 |
| 하데스 수준 손그림 애니 | **안 된다** | 전문 VFX 애니메이터 작업 |

프레임 시트를 만드는 길: (a) GPT로 같은 그림의 연속 장면 — 장마다 모양이 달라져 깜빡임이 심함, 권하지 않음. (b) Godot 입자·셰이더로 굽기 — 수묵 느낌을 내기 어렵다. (c) 사람 손 (외주) — 확실하지만 비용. **지금 단계에서는 셰이더로 갈 수 있는 끝까지 간 뒤** 꼭 필요한 2~3개(해일검기 물결, 반격 불물결)만 시트를 검토하는 것을 권한다.

## 6. 추천 순위와 비용

| 순위 | 할 일 | 고치는 것 | 비용 | 새 그림 |
|---|---|---|---|---|
| 1 | **그림 흘리기·일렁임 셰이더** (`ink_decal`에 흐름 방향·세기, 기술 데이터로) | "떠 있기만 한 그림" — 물이 흐르고 불이 일렁이고 먹이 번진다. 순신 4개·해시계 바늘 그림자 우선 | 1일 | 없음 |
| 2 | **판정 크기 맞추기** (그림 지름 = 판정 지름, 강화 단계로 판정이 커지면 그림도) | "맞을 것 같지 않은데 맞음" (해시계·매화·화폭) | 반나절 | 없음 |
| 3 | **큰 기술 컷인** (반격 3종 + 정복자: 먹 띠가 화면을 가로지르고 영웅 얼굴 + 기술 이름, 200~300ms 느림) | "필살기" 신호, 던파식 | 1일 | 없음 (영웅 카드 재사용) |
| 4 | **국악 소리 층** (기술마다 시전음 + 맞을 때 겹, 해시계 편경·반격 북·정복자 징·매화 가야금) | 소리가 기술마다 같음 | 반나절 + 소리 구하기 (CC0 국악기 또는 사용자 제작) | 소리 파일 |

순신 기술·세종 해시계는 1·2·3을 먼저 적용하는 것을 권한다 (해일검기 흐름, 해룡참 물결 흐름, 반격 컷인, 해시계 판정 크기).

## 7. PR #38과의 관계

PR #38은 2장 표의 "예고·충격·잔상·지면 자국·화면 반응" 층과 "조각 등장"을 채웠다 (스킬별 현황 조사표 포함). 이 벤치마크로 보면 방향은 맞고, 남은 큰 구멍은 **본체 유지 중의 움직임(1순위)**, **판정·그림 크기(2순위)**, **컷인·소리(3·4순위)**다. 사용자가 순위를 고르면 PR #38 위에 이어서 구현한다.
