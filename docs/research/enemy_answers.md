# 적마다 통하는 수 — "정답 표" 제안서 (초안, 2026-11-25)

사용자 결정(2026-11-24): "하자, 완전 찬성". 이번 문서는 설계와 한산 견본까지다. 전면 적용은 승인 뒤에 한다.
조작은 오늘 바뀐 규칙을 기준으로 한다.

- **연타**: 세 번 이은 뒤 한 번 더 치면 4타 마무리. 순신·광개토는 쿨타임 없이 매 바퀴 나간다.
- **내닫아 치기**: 튕긴 내닫기가 적에 닿으면 둘째 기술이 저절로 나간다 (#168).
- **모아 치기**: 꾹 눌러 모았다가 놓는다.
- **피하고 반격**: 예고를 내닫아 벗어나면 1초간 강화 반격.

## 원칙

1. **"그 수면 훨씬 빨리 잡는다"이지 "그 수가 아니면 못 잡는다"가 아니다.**
   - 다른 수로 친 피해는 `others_mult`로 줄인다. 0.2 아래로는 내리지 않는다.
   - 한 손 조작, 입문자, 연타만 하는 사람도 끝까지 깬다.
2. **플레이어를 막지 않고, 적이 똑똑해진다.** 난도 원칙(보통·어려움·지옥)과 같다.
   - 정답 표는 수치를 부풀리는 장치가 아니다. 적의 몸(갑옷·거리·틈)이 정답을 만든다.
3. **정답은 화면에서 읽혀야 한다.** 실루엣, 예고, 작은 표식 중 하나로 보이게 한다. 조작 안내에는 한 줄로 넣는다.
4. **영웅별 수치는 데이터로 둔다.** `EnemyData.answer` = `EnemyAnswerData` (`kind`, `mult`, `others_mult`).
   - 계산은 `EnemyAnswer.scaled` 한 곳에서 한다.
   - 피해를 넣는 네 길이 자기 조작 종류를 알린다.
     - 평타는 연타로 센다.
     - 돌진 타격은 내닫기로 센다.
     - 기술은 `SkillContext.slot`으로 정한다: TAP(4타)=연타, DASH=내닫기, CHARGE=모아 치기, COUNTER=반격.

## 정답이 읽히는 표시 (제안)

| 정답 | 화면에서 | 조작 안내 한 줄 (처음 만날 때) |
|---|---|---|
| 연타 | 따로 없음 (기본) | "떼는 세 번 잇고 한 번 더 — 마무리가 둘레를 쓸어 버립니다" |
| 내닫아 치기 | 조준선이 그려지는 동안 총구에 작은 불씨 (쏘기 전 틈) | "쏘기 전에 튕겨 붙으세요 — 내닫기가 닿으면 기술이 나갑니다" |
| 모아 치기 | 갑옷 테두리가 금속빛, 모아 친 뒤 금이 가는 자국 | "갑옷 입은 적은 꾹 모아 치면 자세가 무너집니다" |
| 피하고 반격 | 예고가 길고 붉은 테두리가 두껍다 (#164 테두리 층) | "큰 공격은 피한 뒤 반격하면 크게 들어갑니다" |

- 표식은 적 그림에 작게 겹치는 낙관 하나로 한다(먹 도장 모양, 영웅 쪽 색이 아닌 무채색). 색 규칙(#164: 순적색은 적 위험 전용)을 지킨다.
- 맞는 수로 맞으면 피해 숫자 옆에 작은 "통!" 글씨와 한 박자 더 센 소리를 낸다. 화면 글씨는 우리말만 쓴다.

## 보통 / 어려움 나누기

- **보통**: 정답 배율만 쓴다. `mult` 2~3, `others_mult` 0.5~1.
  - 연타만 해도 깨지만, 섞어 쓰면 훨씬 빨리 깬다.
  - 표시와 안내 한 줄도 넣는다.
- **어려움**: 적이 정답을 피하려고 움직인다(똑똑한 적, 수치 부풀리기 아님).
  - 철포병은 붙으면 물러나며 쏜다.
  - 무사는 모으는 걸 보면 다가와 끊는다.
  - 정예는 반격 시간에 한 번 막는다.
  - 배율은 보통과 같다.
- **지옥**: 두 종류가 서로 지킨다(무사가 철포병 앞을 막는다 등). 배율은 그대로.

## 한산 기본 켬 (2026-11-25, 보통 난도)

메인 결정: 한산은 기본 켬으로 마무리하고, 나머지 세 전장은 표 초안까지만 쓴다. 보통 난도는 "알면 편해지는" 정도만 넣고, 강한 강제는 어려움으로 미룬다.

### 값 (견본에서 부드럽게)

| 적 | 정답 | 견본 `mult` / `others_mult` | **켬** |
|---|---|---|---|
| 졸병 | 연타 | 1 / 1 | 1 / 1 |
| 철포병 | 내닫기 | 2 / 1 | 2 / 1 |
| 무사 | 모아 치기 | 3 / 0.5 | **2.5 / 0.85** |
| 사무라이 | 반격 | 3 / 0.6 | **2.5 / 0.85** |
| 북잡이 | 모아 치기 | 2.5 / 0.6 | **2 / 0.85** |
| 사무라이 대장 | 반격 | 3 / 0.6 | **2 / 0.85** |

- 견본 값(갑옷 0.5~0.6)은 연타만 하면 순신 +42%, 사임당 +65% 늘었다. 보통에는 너무 세다.
- `others_mult` 0.85는 "갑옷이 조금 덜 받는다" 정도다. 맞는 수(2~2.5배)를 알면 빨리 잡는다.
- 몹 체력은 바꾸지 않았다.

### 화면 · 소리 (`AnswerCue`, `data/feel/answer_cue.tres`)

| | 언제 | 글자 · 색 | 소리 |
|---|---|---|---|
| 통함 | 맞는 수로 맞힘 (`mult` > 1) | "통!" · 한지 금빛, 불꽃, 작은 흔들림 | 국악 방울 (`gugak_bang`) |
| 튕김 | 다른 수, 갑옷이 덜 받음 (`others_mult` < 0.95) | "튕김" · 먹 회색 | 쇳소리 (`mat_blade`, 높게) |

- 조작 안내가 끝날 때 "전장으로!" 아래에 한 줄을 띄운다: "적마다 잘 듣는 수가 있습니다 — 그 수로 치면 "통!" 하고 크게 들어갑니다". 3초 동안 보인다.
