# 시나리오 설계 메모 (제안, 미확정)

> **제안, 미확정.** 사용자가 정한 것이 아니다. 정본 `docs/scenario.md`에 넣지 않고(CLAUDE.md 5번), 여기에만 둔다.
> 사용자가 승인하면 그때 정본으로 옮긴다.

## 소환 결정에서 따라 나오는 설계 (2026-11-24, 사용자 결정 "적들의 망령이 깨어났고 한얼이 영웅들을 불렀다"에서)

- 각 전장은 망령이 깨어난 그 전장이므로, 영웅이 다른 영웅의 전장(원정)에 서는 것도, 같은 전장을 다시 깨는 것도 이 틀 안에서 설명할 수 있다.
- 노량도 순신의 마지막 전장이지만, 영웅으로서의 순신은 거기서 끝나지 않는다 (원정·난이도·나중 전장에 계속 선다).

## 정해진 것 / 정해지지 않은 것

- 정해진 것: 망령이 깨어났고 한얼이 영웅들을 불렀다 (`scenario.md` 3.1.1, 4장 #2, 1.1).
- 정해지지 않은 것: 망령이 왜 깨어났는지(4장 #1·#3), 한얼이 무엇인지.
