## 1. 세계관

### 1.1 한얼

'한얼'은 한국의 역사와 영웅들이 남긴 정신을 상징하는 이름이다.
게임 세계에서는 **시대를 초월하여 이어지는 영웅의 혼과 초월적인 힘**으로 해석한다.

- 중심 문장: **"시대는 달라도 영웅의 혼은 이어진다."**
- 대표 슬로건: **"역사가 전설이 된다."**

역사 속 위인들은 서로 다른 시대에 살았지만, 한얼을 매개로 하나의 세계에 모일 수 있다.
한얼은 영웅마다 다른 형태로 발현된다.

| 영웅 | 한얼의 발현 |
|---|---|
| 이순신 | 물결 |
| 광개토대왕 | 천둥 |
| 세종대왕 | 문자 마법 |
| 신사임당 | 수묵술 |

한얼의 **기원과 구체적인 작동 원리는 미확정**이다.

### 1.2 분위기

- 한국적인 역사·문화·미술적 요소
- 장대한 동양 판타지
- 초월적인 영웅들의 집결
- 전통 무기와 초자연적 능력의 결합
- 강렬한 전투와 신화적인 연출
- 어둡고 웅장하지만 지나치게 음울하지 않음

### 1.3 재해석 원칙

- 역사적 사실을 그대로 재현하는 교육용 게임이 아니다.
- 실존 인물을 **존중하면서** 창의적으로 재해석하는 판타지다.
- 기존 게임의 캐릭터·아트·스토리·UI를 복제하지 않는다.
- 영웅은 모두 **20대 청년의 모습**으로 그리고, 게임 안에서는 **이름으로 부른다**: 순신·세종·사임당·광개토.

## 2. 플레이어블 영웅

초기 구성은 4인이다. (장보고는 초기 구성에서 제외되었다.) 괄호 안은 역사 속 인물이다.

### 2.1 순신 (이순신) — 푸른 해류의 검

- **역할:** 근접·원거리 복합형 검사
- **전투 콘셉트:** 푸른 물결과 검기, 빠르고 정교한 검술, 대시로 적진 관통, 주변 광역 베기, 물결 형태의 원거리 검기
- **전투 이미지:** 푸른 해류를 두른 검, 적진을 가로지르는 돌진, 파도처럼 연속되는 참격, 해일을 연상시키는 충전 공격
- **위치:** P0 프로토타입의 첫 플레이어블 캐릭터
- **P0 기술(가칭):** 무영보(대시), 해룡참(주변 광역), 파도격(대시 중 관통 연격), 해일검기(충전 원거리)

### 2.2 광개토 (광개토대왕) — 천둥의 정복자

- **역할:** 중량급 돌진형 전사
- **전투 콘셉트:** 거대한 대검, 천둥과 번개, 강력한 돌진, 넓은 범위 타격, 압도적인 힘과 돌파력
- **대비:** 이순신이 유연하고 정교하다면, 광개토대왕은 무겁고 파괴적이다.

### 2.3 세종 (세종대왕) — 천문의 지배자

- **역할:** 원거리 마법형 영웅
- **전투 콘셉트:** 한글 문자 마법, 천문과 별자리, 문자와 기호를 활용한 공격, 원거리 광역 마법, 독창적인 주문 연출
- **해석:** 세종대왕의 지식과 창조성을 판타지 전투 능력으로 재해석한다.

### 2.4 사임당 (신사임당) — 수묵의 술사

- **역할:** 자연·소환·광역 마법형 영웅
- **전투 콘셉트:** 수묵화, 붓과 먹, 꽃과 나비, 그림에서 나타나는 생명체, 아름다우면서도 강력한 자연계 마법
- **연출 목표:** 전투 화면에서 한국 전통 회화가 살아 움직이는 듯한 연출

## 3. 게임 경험과 스토리의 관계

- 핵심 경험: 다수의 적을 빠르게 처치하는 쾌감, 이동과 대시로 적진을 누비는 재미, 상황에 따라 달라지는 단일 버튼 스킬, 판단과 타이밍으로 강해지는 전투
- 조작 원칙: **"버튼은 적지만, 액션의 깊이는 깊다."**
- P0는 전투 재미 검증이 목적이며 **정식 스토리 캠페인은 P0 범위 밖**이다.
